# LECTURE 교재 다시 짜기 (2026-10-20, 사장님 "촌스러운 티 싹다 없애 · 교재 틀도 없애 · 오타 싹다 고쳐")

교재 쪽 그림(.gdb 속 827×1169 JPG)을 새 글씨체(Pretendard, SIL OFL)로 다시 짠 2배 크기 그림으로 바꾼다.
**낱말마다 옛 글자의 잉크 자리에 새 글자를 놓는다** — 선생님 필기는 교재의 위치에 그려지므로 아무것도 움직이면 안 된다.

1. `registry.py` — 강의가 쓰는 서로 다른 인쇄 쪽 목록(책 · 쪽 · 쓰는 강의). 뼈대세우기의 빈 쪽은 손대지 않는다.
2. `prep.py` → `analyze.py` · `crops.py` — 쪽마다 그림 요소(긴 가로 · 세로 선, 회색 바탕)와 글자를 나누고, 줄 · 낱말 상자를 찾고,
   읽는 AI용 3배 줄 그림을 만든다. 표 칸처럼 여러 줄에 걸친 상자는 `split.py` 로 다시 나눈다.
3. AI 둘(읽기 · 따로 대조)이 상자마다 글자 · 굵기 · 밑줄 · 오타(바른 글자 + `printed`)를 `page.read.json` 에 적는다.
4. `render.py` — 흰 바탕 2배 쪽: 옛 틀(테두리 · 붉은 줄 · 입체 상자 · 쪽 번호)은 빼고, 회색 바탕 · 예문 상자는 연한 둥근 바탕,
   장 제목 아래 점선은 얇은 선, 밑줄 · 괄호선은 선명하게 다시, 낱말은 줄마다 한 크기 · 한 기준선으로 옛 잉크 자리에.
   Pretendard 에 없는 글자(㉠ ☞ ⇩)는 맑은 고딕 · Segoe UI Symbol 로. `render_all.py` 가 전체를 그리고 점검값(빠진 상자 ·
   자리 어긋남 · 그대로 옮긴 잉크)을 남기며, 완성 그림을 `.lecture-media/retype/<book>-<NNN>.jpg` 에 둔다(유료 · 비공개).
5. `build-lecture.mjs` 가 그 그림이 있으면 옛 쪽 대신 쓴다(쪽의 머리 이름표만 남기고 꼬리 가림은 뺀다).
6. `penover.py` — 옛 쪽 · 새 쪽에 같은 필기를 그려 나란히 비교.

경로는 이 작업을 한 컴퓨터의 임시 폴더 기준으로 적혀 있다(다시 쓸 때 맞춰서).
