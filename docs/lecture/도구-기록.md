## 1. 바늘을 무엇으로 — 정한 것과 이유

LECTURE 강의 파일(`content/lessons/lecture/<id>.json`)에는 유료 **글**이 없다. 제목 · 장 이름(목록에 공개)과 미디어 주소뿐이다.
유료 내용은 비공개 R2 의 교재 쪽 그림(`audio/lecture/<id>/p<NN>.jpg`)과 필기(`pen.json`)이고, 강의 화면은 그것을 `/audio/lecture/...` 로만 부른다.
그래서 도구마다 다음처럼 정했다(각 도구 머리말에 같은 이유를 적음).

| 바늘 | 어디서 | 왜 |
|---|---|---|
| **잠긴 강의의 미디어 주소** — 강의 파일의 `lecture.pages[].src` · `lecture.pen.src` · 나중의 `lecture.audio.src` 그대로 (예 `/audio/lecture/lm050/p050.jpg` · `/audio/lecture/lm050/pen.json`) | 공개 JS · JSON(번들 탐침) · 공개 색인(paidLeakCheck) · 잠긴 강의 HTML · RSC(이용권 탐침) | 그림 바이트는 글자 검색으로 못 찾는다. 앱의 약속은 '잠긴 강의 화면 · 공개 파일에 그 강의의 그림 · pen 주소 0'(확인-기록 3장). 주소가 공개되면 잠긴 강의 내용을 부를 길이 공개된 것. 평문(글자만)으로 바꾸면 `audiolecturelm050p050jpg`(24글자) — JSON 의 `\/` 꼴도 같은 글자 |

앱(`src/`) 문제: 찾지 못함. `GET /api/admin/lecture-progress` 는 405(POST 만 있음 · 본문 없음 — ADULT 와 같은 꼴, 문제 아님 → probe-security 에 GET 줄을 넣었다가 뺌).

도구 쪽에서 고친 것(2장 표에 같이 적음): plan-access `--break=drop-passoff` 가 10-02 이후 아무것도 깨지 않던 것 · bundle-leak 의 RSC 줄이 307 로 빈 글만 받던 것.

남은 것 — 주 세션 몫(이번에 고치지 않음, 유출 검사 도구가 아님):

1. **`check-completeness.cjs` 가 lecture 에서 exit 2**("'필요한 부분' 규칙이 없는 과정: lecture"). LECTURE 의 '필요한 부분'(그림 · pen 주소가 있음 · 클립 0) 규칙을 넣어야 돈다.
2. **`check-unreached-data.cjs` 가 lecture 에서 멈춤**("lecture: LessonBody 에서도 page.tsx 에서도 화면 부품을 못 찾음") — 공통 강의 쪽의 `course === "lecture"` → LectureLearningView 분기를 그 도구가 못 읽음.
3. **`check-search.cjs` 3번 '1강'** — 기준선이 HEAD(커밋된) 색인이라 LECTURE 항목(중등 영어독해 1강 · 고등 영어독해 1강)이 커밋되기 전엔 늘 다름. 유출과 무관(2번 0줄). LECTURE 를 커밋하면 사라질 것 — 그때 다시 돌려 볼 것.
4. `lib/expectations.cjs` 의 COURSES(드라이버 · build-coverage 등이 씀)에 lecture 없음 — 화면 드라이버 규칙이 없는 과정이라 넣지 않음. `scripts/lib/spoken-texts.cjs` SPOKEN_COURSES 에도 일부러 넣지 않음(1장 · audio-inventory 머리말).
5. `probe-privacy.cjs` 의 쪽 목록(법정표시 · 외부 스크립트)에 `/lecture` · `/lecture/lm001` 없음 — 브라우저를 띄우는 도구라 이번엔 손대지 않음.
6. `docs/pass-off-grammar/검사/check-leak-fix.cjs`(09-28 wordForms 한정 검사)의 과정 목록엔 adult · lecture 가 없지만, 그 검사가 보는 것(무료 PASS-OFF 문항의 wordForms)에 미디어 주소가 들어갈 길이 없어 그대로 둠.
7. 운영에서는 아직 못 돌림(배포 전). 배포 뒤: `probe-bundle-leak-all.cjs`(로컬 사본이 있는 곳에서 — 필기 바늘까지) · `probe-entitlement-all.cjs` · `audio-inventory.cjs` → `audio-check.cjs --anon`(운영은 클립까지) · `probe-security.cjs --no-mutating-routes`.
8. 알아 둘 것: `--base` 로컬 결과 — `probe-bundle-leak-all` 은 전처럼 `out/bundle-leak-all.json` 에 쓴다(이번 로컬 결과가 그 파일에 있음 · 운영 기록은 날짜별 폴더에 따로 있음). `probe-entitlement-all` · `probe-security` 는 이제 운영이 아닌 주소면 `-local` 이 붙은 파일에(전에는 BASE 를 바꿔도 운영 결과 파일을 덮었다).
9. 미디어 문지기는 이용권만 보고 장 순서는 보지 않음(만들기-기록 5장 · 확인-기록 7장 3과 같음 — 이 도구들도 이용권 없는 쪽만 봄).
