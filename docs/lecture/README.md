# LECTURE — 강의 섹션 (2026-10-17 ~)

GVA 독해 강의 200개(중등 영어독해 100 · 고등 영어독해 100)를 새 섹션 **LECTURE** 로 넣는다.
음성은 넣지 않는다. 사장님이 나중에 강의마다 AI 음성을 따로 만들 것이므로, **강의를 재생하면 처음부터
교재 쪽 위에 선생님 필기가 원래 시간 그대로 그려져야 한다.** 이 문서가 기준이다 — 일하기 전에 읽고, 바뀐
결정은 맨 아래 기록에 덧붙인다.

## 1. 사장님 결정 (2026-10-17)

## 2. 데이터

`scripts/lecture/build-lecture.mjs` 가 원본 .gdb 200개에서 만든다(파일 형식 설명은 그 파일 머리말).

- `content/courses/lecture.json` — 목록(20장 × 10강, 장 제목 '중등 영어독해 1~10강' …).
- `content/lessons/lecture/<id>.json` — 강의마다: id(`lm001`–`lm100` 중등 · `lh001`–`lh100` 고등) · title ·
  `lecture: { book, number, durationSec, lengthUnits, unitSec, pages: [{page, src}], pen: {src, strokes, segments} }`.
  **유료 내용(그림 · 필기)은 들어 있지 않다** — 저장소는 공개(GitHub PUBLIC)라서.
- 비공개 R2(`audio/lecture/<id>/p<NN>.jpg` · `pen.json`) — `scripts/lecture/upload-lecture-r2.mjs` 로 올림(403개,
  2026-10-17). 브라우저는 `/audio/lecture/...` 로만 받는다 → `src/lib/mediaAccess.ts` 가 이용권을 본다.
  공개 주소(r2.dev)는 401(확인함).
- pen.json: `{ v, id, unitSec, lengthUnits, page:{w:827,h:1169}, canvas:{w,h}, pageEvents:[[t,page]…],
  scrollEvents:[[t,y]…], strokes:[[t0, page, pen, x0, y0, (dt, dx, dy)…]…] }` — t 는 단위(× unitSec = 초),
  x·y 는 GVA 창의 픽셀 — 교재 쪽은 그 창의 (80, 20)에 놓여 있었다(PageNN.htm 의 topmargin=20 · 가운데 정렬,
  강의 27개로 잰 값 ±2). 화면은 교재 그림을 (80, 20)에 놓고 필기는 숫자 그대로 그린다(10-17 사장님 '86강 어색' → 찾아 고침). pen 색(원래 색은 파일에 없음 — 교재의 진홍 줄 ·
  사이트의 먹색 · 금색에 맞춰 정함, 사장님께 시안 보임 10-17): 0x43 진홍 #C2362F(주 펜 · 획의 90%) · 0x33 잉크 파랑 #2456A4 ·
  0x23 숲 초록 #2E7A4C · 0x13 먹색 #2A2A2A · 0x03 짙은 금색 #A3690F(굵기 2.2 — 10-20 까지는 형광펜 #E8B93A 굵기 13 · 0.42 로
  그렸으나 233강의 0x03 획 1,045개 중 형광펜 같은 납작한 띠는 0개, 뼈대세우기가 빈 쪽에 글씨를 쓰는 펜이라 사장님 "알아볼 수가
  없잖아" → 보통 펜으로). 색은 펜 번호의 앞자리(0x12 · 0x22 · 0x32 · 0x42 · 0x02 — 문장구조론 · 알파오메가 — 도 같은 색).
  어둠 모드에서도 교재 쪽은 흰 종이 그대로라 같은 색을 쓴다.
- 57강은 중간에 쪽을 59 → 60 → 58 → 57 로 넘겼다 돌아온다(약 4초). 182강(고등 82강)은 쪽 기록 없이 시작.
- 그려 보기: `node scripts/lecture/render-pen.mjs <id> [--at <초>]` → SVG.

## 3. 만들 것 (앱)

ADULT 섹션(2026-10-02)이 새 섹션의 본보기다 — 같은 순서 잠금 · 서버 진도 · 이용권 · 무료 체험 · 끝 막대 · 관리자
진도 보기를 그대로 따른다. 학습자 말은 '강의', 디자인은 `docs/디자인-규칙.md`.

1. 과정 · 탭 등록: `src/lib/courses.ts`(slug `lecture`) · `src/lib/tabs.ts`(탭 `lecture`, 라벨 LECTURE) ·
   `src/lib/tabImages.ts`(사진) · 첫 화면 슬라이드 · 메뉴 · 검색 색인 · sitemap · validRoutes · 과정 소개 글(하는 일대로).
2. 이용권: `planOpensCourse` 에서 올패스만 · `FREE_PREVIEW_LESSON_IDS.lecture = ["lm001","lm002"]` ·
   무료 강의의 그림 · pen 키가 `generated/freeMediaKeys.json` 에 들어가게(`scripts/buildFreeSpeechKeys.mjs`) ·
   `mediaAccess.ts` FOLDER_TO_COURSE 에 `lecture`.
3. 순서 잠금 · 진도: ADULT 와 같은 서버 진도(`adultProgress.ts` 본보기) · 잠긴 강의는 서버에서 잠김 화면
   (그림 · pen 주소가 HTML/RSC 에 0) · 목록의 잠금 표시 · 관리자 진도.
4. 강의 화면(새 보기): 교재 쪽 그림 + 그 위 캔버스. 재생 · 일시정지 · 처음부터 · 구간 이동 막대(지금 시간 / 전체 시간) ·
   빠르기(1× · 1.5× · 2×). 시간 T 의 화면 = 그 시각에 보이는 쪽 + 그 쪽에서 t ≤ T 인 필기. 처음엔 빈 쪽(필기 0)에서
   멈춰 있음 — 자동 재생 없음. 끝까지 가면(또는 막대를 끝으로) 완료 켜짐 + 이유 한 줄. 휴대폰은 폭에 맞춤.
   **나중에 AI 음성을 붙일 자리:** lesson.lecture.audio?.src 가 생기면 그 오디오가 시계가 되게(지금은 내부 시계).
5. 끝 막대(`LessonEndBar`) · 단계 탭 없음(한 화면) · 이전/다음 강의.
