## 2. 만든 것

**목록(/lecture)** — '200개 강의 · 20장', 장 머리 '1장 · 중등 영어독해 1~10강' … '20장 · 고등 영어독해 91~100강'. 강의 줄은 '중등 영어독해 1강'.
이용권 없으면 1장만 '1·2강 무료', 나머지 장 '이용권 등록 후 열려요'. 올패스(기간)면 STUDENT · ADULT 와 같은 장 잠금
('N장을 마치면 열려요' · '진행 N% · 8강과 마지막 강의를 마치면 다음 장'), LIFE 는 다 열림.

**잠금(서버)** — `/lecture/<id>`: 무료(lm001 · lm002)는 누구나. 아니면 세션 쿠키 + `planOpensCourse(plan, "lecture")`(1M · 1Y · LIFE 만 —
STUDENT 패스는 열지 않음) + LIFE 가 아니면 서버 진도의 장까지. 잠긴 강의는 제목 · 장 줄 + `LessonPaywall` 만 그림 — 강의 파일의
`lecture` 덩어리를 읽지 않으므로 그림 · pen 주소가 HTML/RSC 에 0(로컬에서 잼: lm003 · lh100 HTML 의 'audio/lecture' 0 · 'pen.json' 0).
미디어(`/audio/lecture/…`)는 mediaAccess 가 봄: 무료 강의 파일 4개(lm001 p001.jpg · pen.json, lm002 p002.jpg · pen.json)만 누구나,
나머지는 LECTURE 를 여는 이용권 세션(로컬에서 잼: lm003 pen.json · p003.jpg 이용권 없이 403).

**강의 화면(LectureLearningView)** — 한 화면, 단계 탭 없음. 위에 재생 줄 하나(머리줄 밑에 붙어 따라옴): 재생/일시정지(44px 둥근 단추) ·
구간 이동 막대(보이지 않는 range 입력이 44px 높이로 덮음 — ← → 5초 · PageUp/PageDown 30초 · Home/End) · '지금 m:ss / 전체 m:ss'(전체 =
`lecture.durationSec`) · 빠르기 단추 하나(1× → 1.5× → 2×, AudioPlayer 처럼 누를 때마다 바뀜) · '처음부터'.
그 아래 무대: 교재 쪽 그림(`<img>` — 쪽마다 하나, 지금 쪽만 보임) 위에 형광펜 캔버스(반투명 · multiply), 그 위에 펜 캔버스.
- 시간 T 의 화면 = `pageEvents` 로 정한 그 시각의 쪽 + 그 쪽의 선분 중 시각 ≤ T 인 것(획 중간까지). 시각 = 단위 × unitSec.
- 재생 중엔 매 프레임 새로 닿은 선분만 더 그림. 뒤로 감기 · 쪽 넘김 · 화면 크기 바뀜 때만 그 쪽을 처음부터 T 까지 다시 그림.
- 시계: `performance.now()` 내부 시계. 강의 파일에 `lecture.audio.src` 가 생기면 그 `<audio>` 가 시계가 됨(코드 경로만 — 지금 데이터엔 없어 실제로 돌려 보지 못함).
- 처음 열면 0:00 · 빈 쪽 · 멈춤. 자동 재생 없음(로컬에서 잼: 연 뒤 소리 · 재생 사건 0).
- 무대 크기: 모든 강의 같은 1020×1170(쪽 827×1169 + 오른쪽 여백 필기 — pen.json canvas.w 가 200개 중 840~1020). pen 을 받기 전에도
  자리가 같아 튐 없음. 넓은 화면에선 창 높이에 맞춰(머리줄 · 재생 줄을 뺀 높이) 쪽 전체가 한 번에 보이게 줄어듦 — CSS 만으로.
- 선명함: 캔버스 픽셀 = 화면 폭 × devicePixelRatio(최대 3).
- 펜 색: README 2장 그대로(0x43 빨강 · 0x33 파랑 · 0x23 초록 · 0x13 검정 · 0x03 노란 형광펜 굵게 반투명). 교재 잉크라 디자인 토큰 밖 —
  부품 안 상수 + 이유 주석(design 검사기의 directColor 는 Tailwind 색 클래스만 세므로 예외 표시는 필요 없었음).
- 불러오는 중: '강의를 불러오는 중이에요…'(무대 자리 그대로). 실패: '강의를 불러오지 못했어요. 인터넷 연결을 확인하고 다시 시도해 주세요.' + '다시 시도'(pen 과 그림을 다시 받음).
- 완료: 끝까지 가면(재생으로든 막대 · End 키로든) 끝 막대의 '이 강의 학습 완료'가 켜짐. 그 전엔 꺼져 있고 아래 '강의를 끝까지 재생하면 완료할 수 있어요.'
  완료는 다른 과정처럼 학습자가 누름 → 올패스면 서버 진도로 감(ADULT 와 같은 줄) → '다음 강의'는 저장을 기다린 뒤 이동.

**머리** — 제목 '중등 영어독해 1강', 아래 줄 '1장 · 중등 영어독해 1~10강', '← LECTURE 목록' · 북마크. 끝 막대: 이전/다음 강의(lm100 다음은 lh001).

**등록** — 첫 화면 슬라이드 9번째(STAGE 09, READING 다음 · CNN 앞 — 첫 화면은 탭에서 만들어지므로 탭 하나 더한 것뿐, 모양 그대로) ·
메뉴(탭에서) · 검색(강의 제목 200개, '중등 영어독해 3강' · 'lh051' · '독해' 로 찾힘) · sitemap(/lecture · /t/lecture · lm001 · lm002) ·
validRoutes(lecture 200) · 관리자 'LECTURE 진도'.

## 4. 사장님께 여쭐 것

1. **펜 색** — 빨강 · 파랑 · 초록 · 검정 · 노란 형광펜으로 그렸어요(README 2장). 예전 GVA 프로그램과 색이 같은지 사진(`desktop-lm001-end.png`)을 보시고 알려 주세요.
2. **휴대폰에서 교재 글씨가 작아요** — 교재 쪽이 화면 폭의 약 81%(390 폭 휴대폰에서 약 290px)로 보여요. 두 손가락 확대는 돼요. 확대 단추나 가로 보기 같은 것이 필요할까요?
3. **오른쪽 여백** — 200강 중 116강은 쪽 오른쪽 바깥에 필기가 없어서, 모든 강의에 같은 넓이(오른쪽 흰 띠 포함)를 쓰면 그 강의들은 오른쪽에 빈 흰 띠가 남아요. 지금은 '모든 강의 같은 넓이'(불러올 때 화면이 튀지 않음)로 했어요. 강의마다 맞추려면 강의 파일에 넓이 하나를 더 넣어야 해요(데이터 다시 만들기 — 주 세션 몫).
4. **첫 화면 슬라이드 자리와 영어 한 줄** — READING 다음(9번째, CNN 앞)에 'LECTURE · Reading Passages with the Teacher's Notes' 로 넣었어요. 자리 · 문구 괜찮을까요?
