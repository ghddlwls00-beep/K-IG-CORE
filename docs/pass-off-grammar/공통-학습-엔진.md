> 원칙: 기존 섹션의 문장·번역·음성은 바꾸지 않는다. 섹션마다 어댑터로 붙이고, 붙일 때마다 그 섹션의 화면·소리·채점 점검을 다시 한다.
> **섹션마다 공부 방법은 다르다(사장님 확인, 2026-09-27).** 레슨 안의 학습 단계는 자료에 맞게 섹션마다 따로 둔다.
> - VOCA: 낱말 뜻 떠올리기·발음
> - LISTENING: 안 보고 듣기·받아쓰기·연음
> - READING: 빠르게 읽기·어휘·이해
> - GRAMMAR I·II: 한→영 영작
> - STUDENT: 받아쓰기·따라 말하기·외워 말하기
> - PASS-OFF GRAMMAR: 예문·규칙·형태 찾기·영작
>
> 엔진이 공통으로 맡는 것은 **날을 넘기는 부분(날짜 · 통과 판정 · 오답노트 · 신고)뿐**이다. 무엇을 다시 푸는지는 섹션 어댑터가 정한다. 예: VOCA 는 낱말, LISTENING 은 받아쓰기 문장. 모든 섹션을 같은 단계로 만들지 않는다.

## 1. 엔진이 하는 일

| 기능 | 학생에게 보이는 것 | 근거(학습 연구) |
|---|---|---|
| 오늘 할 일 | 과정 첫 화면의 "오늘 학습 시작 · 약 N분" 버튼 하나 | 부담을 줄이고 매일 하게 |
| 다음 날 확인 | 어제 배운 레슨을 시험처럼 풀고 결과를 한꺼번에 | 테스트 효과 · 교재 Review |
| 날을 두고 복습 | 2 · 4 · 8일, 3주 · 2개월 · 4개월 | 간격 효과(강함) |
| 통과(Pass-Off) | 서로 다른 날 3번 첫 시도 정답이면 문장에 통과 표시 | 연속 재학습(강함) |
| 섞기 | 두 번째 복습부터 여러 레슨·헷갈리는 짝을 섞음 | 섞기(중간) |
| 오답노트 | 레슨별 틀린 문장·유형, "지금 다시 풀기" | 학습자 기대 · 교재 학습법 4 |
| "내 답도 맞아요" | 채점이 틀렸다고 신고 → 보류(진도 안 깎임) → 주 1회 판정 | 허용 답 보강 |

## 2. 공통 개념 (과정 이름에 매이지 않음)

- **문항(item)**: `{ course, lessonId, itemId, kind }`. 문항 내용(문제·정답)은 과정의 레슨 데이터에 있고, 엔진은 id 만 기록한다.
- **시도(attempt)**: `{ at(서버 시각), day(한국시간 오전 4시 경계), firstTry(bool), correct(bool), help: none|hint|tiles|reveal, mode: typed|voice|tap, pending(bool, 신고 보류) }`.
- **상태(state)**: new → learning(R1~R3) → passed → maintenance(21 · 60 · 120일) / due(복습 필요).
- **통과 규칙(기본값, 과정별로 바꿀 수 있게)**: 첫날 제외, 도움 없이 첫 시도 정답인 **서로 다른 날 3번**, 그중 한 번은 첫날로부터 6일 이후, 마지막 시도도 정답. 요소(형태 찾기) 문항은 2번.
- **일정**: 1일(레슨) → 2일 확인(R1) → 4일(R2, 섞기 시작) → 8일~(R3) → 통과 → 21 · 60 · 120일 유지(레슨당 2~3문항, 매번 다른 문장). 틀리면 그 문항만 R1 로.
- **하루 상한**: 복습 30(출발값). 재학습 중 60 초과면 새 레슨보다 복습을 권함(순서 잠금과 별개인 권유). 3일 이상 쉬면 복귀 코스 10.
- **충돌**: 같은 날 두 기기 기록이 다르면 틀린 쪽.
- **말로 답한 것(mode=voice)**: 글자로 바꿔 채점한 결과를 쓰되, 통과 횟수에 넣을지는 과정 설정(기본: 넣음 — 다른 섹션과 같은 마이크 흐름. 음성 인식이 문법을 고쳐 받아쓰는 위험은 기록해 두고 사용자 기록으로 재평가).

## 3. 과정 어댑터 (섹션마다 하나)

```ts
interface CourseAdapter {
  course: string;
  // 이 레슨의 복습 대상 문항 목록(레슨 데이터에서 뽑음 — 서버 전용)
  itemsOfLesson(lessonId: string): EngineItem[];
  // 문항 하나를 화면에 그리는 컴포넌트 종류와 채점 함수
  kinds: Record<string, { render: 'produce' | 'select' | 'choice' | 'short' | 'dictation' | 'word'; grade: (item, answer) => Verdict }>;
  // 헷갈리는 짝(섞기용) — 태그 기반
  confusablePairs?: [string, string][];
  passRule?: Partial<PassRule>;
}
```
- PASS-OFF GRAMMAR: produce · select · choice · short · transfer.
- 옆 세션 몫(기존 섹션): STUDENT(문장 받아쓰기 타일 · 따라 말하기), VOCA(낱말), GRAMMAR I·II(영작), LISTENING(받아쓰기), READING(어휘·빈칸). 어댑터 모양은 v1 에서 옆 세션 검토를 보고 확정.

## 4. 저장과 보호

- 이용권 키별 · 과정별 R2 비공개 객체(STUDENT 진도와 같은 암호화 방식, 새 파일). 쓰기는 단계·회차가 끝날 때만 묶어서.
- "오늘 할 일" 페이지는 서버가 이용권을 확인하고 → 진도를 읽고 → **오늘 낼 문항의 데이터만** props 로 넘긴다. 유출·잠금 탐침 대상에 반드시 추가.
- 무료 체험 학생은 기기에만 기록하고, 이용권을 넣으면 한 번 서버로 옮긴다.
- 로컬 대체 저장소(data/…json)로 시험. 운영 저장소 열쇠는 이 컴퓨터에 없음.
