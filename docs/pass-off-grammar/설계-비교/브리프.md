# 설계 브리프 — Pass-Off Grammar 를 K-IG CORE 웹 학습 섹션으로 (2026-09-26)

이 파일은 1차 조사(교재 191쪽 전수 추출 7명 · 사이트 구조 지도 1명 · 학습과학 조사 1명 · 제품/기술 조사 1명)와
기계 검사 결과를 한곳에 모은 것입니다. 숫자는 모두 스크립트로 잰 값이고, 판정은 에이전트들이 스스로 점검한 것이라
독립 검수가 아닙니다. 세부가 필요하면 맨 아래 "원자료 경로" 를 여세요.

## 0. 과제

사장님(비개발자)이 STUDENT 섹션 옆에 새 학습 섹션을 만들려 합니다. 재료는 자기 회사 교재 "Pass-Off English
Grammar 1·2·3"(2012, 191쪽)입니다. "a~z 까지 학생을 어떻게 학습시킬지 최고의 방법"을 원합니다.

## 1. 교재 사실 (잰 값)

- 3권: Part 1(1권 63쪽, TOPIC 1~8) · Part 2(2권 71쪽, TOPIC 9~15) · Part 3(3권 57쪽, TOPIC 16~20).
  대주제 20개. 소주제(연결고리)는 본문 기준 67개, 교재 소개글은 "70개", 구성도 동그라미도 67개.
- 대주제 목록: 1 인칭 · 2 동사의 현재형 · 3 문장의 기초(5형식·8품사·구) · 4 문장의 종류(+부정문) · 5 의문문 ·
  6 명사 · 7 대명사 · 8 관계대명사 · 9 형용사(+비교·최상·관사) · 10 동사(종류·불규칙동사표) · 11 시제 ·
  12 완료와 진행 · 13 준동사 · 14 태 · 15 화법 · 16 가정법 · 17 조동사 · 18 부사 · 19 전치사 · 20 접속사.
- 목차·구성도와 본문이 어긋나는 곳(구조 결정 필요): 'Have/Has'(본문에 따로 없음), '동사 — ed와 -ing'(본문 없음),
  '가정법 미래'(본문 없음), '가정법 현재'·'의문부사'(목차에 없음), 부사 소주제 번호 (2) 중복, TOPIC 4 는 목차(단문·중문·
  복문·서술문/명령문/기원문·감탄문)와 본문 소제목((1) 문장의 종류 (2) 부정문)이 다름, 조동사 목차 '조동사 1·2·3' ↔ 본문 can/may/should….
- 모든 대주제가 같은 3단 구조:
  ① Pass-Off Sentences(소주제별 핵심 예문, 초점어 굵게 — 단 2권 후반·3권은 굵게 표시가 거의 없음)
  ② Application Sentences(Pass-Off 문장을 거의 다 다시 싣고 확장. 소주제 머리글이 인쇄되지 않은 토픽이 많음)
  ③ Review(Application 문장의 한국어 번역을 같은 순서로 주고 영작 + 문법 요소 찾기)
- **문법 설명 문단이 거의 없음.** 소제목, 짧은 태그((단수)(가주어)), 목록 몇 개(복수형 규칙, 대명사표, 불규칙동사표)뿐.
  학습법 2~3항이 "교사의 문법 설명"을 전제함 → 웹에서는 설명을 새로 만들어야 함.
- **정답지 없음.** 그러나 Review 1,067문항 중 954문항(89%)은 같은 토픽의 책 영어 문장이 그대로 정답(순서 1:1).
  추출자들이 새로 제안한 답 32개, 그 밖에 81개는 요소 찾기 전용(정답 = extraSlotAnswer 에 새로 작성).
- 문장 수: 예문 줄 1,334(Pass-Off 446 + Application 888), 정규화 중복 제거 912문장.
  - 912 중 한국어 번역이 책(Review)이나 STUDENT 에 있는 것 724, **없는 것 188**
    (태 38/38, 화법 41/41, 의문문 30/46, 형용사 17, 준동사 17, 부사 12, 시제 10 …) → 새 번역 필요.
  - 소주제별 Application 묶음 크기: 중앙값 13문장, 상위 25% 20문장, 최대 56문장(3권은 머리글 없이 한 묶음).
- Review 과제 유형(책 표현 → 수):
  - 한→영 영작(약 620+ 문항, 압도적 다수)
  - 영작 + 요소 표시: 인칭대명사 밑줄+인칭(8), be동사 동그라미(4), 일반동사 원형 쓰기(4), 몇 형식(6+29),
    문장 종류 분류(21), 명사 동그라미(26), 관계사 힌트 영작(14), 지정 요소 사용 영작(57), 최상급/관사 사용(7/16)
  - 굵은 단어 품사(29), 형용사 밑줄(12), 부사 밑줄(12), 조동사 밑줄+의미(11), 접속사 밑줄+등위/종속(17)
  - yes/no 단답(19), 불규칙동사 과거·과거분사 표(110행), 영→한 해석+시제 이름(27), 시제에 주의한 해석(16),
    굵은 부분 해석(12), 시제 일치 변형(7), 공식 쓰기(1), 빈칸(8), 능동↔수동(8+20), 직접→간접화법(18), 같은 뜻 바꿔쓰기(7)
  - 선택형·듣기·말하기 과제는 책에 없음. 종이 전용 동작(밑줄·동그라미·괄호) → 웹은 단어 탭 + 버튼.
- 난이도: 대상은 "초급자"(학습법 1)지만 토픽 안에서 초등~고등 수준이 섞임(TOPIC 3 에 미래완료·in case~should 등).
  Review 순서 = Application 순서라 순서 기억으로 풀 수 있음(섞기 필요).
- **STUDENT 연결**: 교재의 "(N과)" = 사이트 STUDENT 과정 Chapter N. 꼬리표 239줄 중 144줄은 STUDENT 해당 장 문장과
  정확히 일치, 47줄은 은퇴한 'middle' 과정 문장과 일치(옛 판), 38줄은 문법용으로 바꾼 문장(의문문화·축약), 6줄은 장 번호 오류.
  STUDENT 연결은 1권·2권 시제·3권 전치사/접속사에 몰려 있고, 형용사·동사·태·화법·가정법·조동사·부사는 일반 문법책 예문.
  교재 소개글의 "560여 문장"은 STUDENT 414 문장 항목(419 문장)에 해당.
- **음성**: 912문장 중 이미 사이트에 클립이 있는 것 66개(글자까지 같은 문장). 846개는 새로 만들어야 함
  (약 4만 자 — Azure 무료 한도 월 50만 자 안). 고친 문장은 텍스트 해시가 바뀌므로 확정 후에 생성.
- **오류 후보 548건**(중복 제거 541): 한국어-영어 뜻 불일치 146, 영어 문법 오류 109, 어색한 영어 92, 한국어 오타 78,
  문법 설명 오류 49, 정답 모호 30, 조판/추출 37, 정답 없음 6, 시대 사실 1. 학습 영향 high 로 표시된 것 80건(3권 파일은 severity 미기재).
  대표: 불규칙동사표 7행(send-send-send, show-show-show, understand×3, strive-stove, bite-bit-bit, hide-hid-hid, bear-born),
  'I have just have lunch.'(완료 단원 첫 예문), 'She is best mother in the world.', 'A new car was promised to me by him.'(정답 틀림),
  '너는 지금 떠나는 것이 낫다' ↔ You'd better not leave now(뜻 반대). 한국어 제시문 오역은 학생이 제시문대로 써도 오답 처리됨.
  내용 민감(사장님 판단 필요): 'In Saudi, one man can have many wives.', 'You are fatter than her.', 'Mr. Hillman was a crazy man.',
  일제강점기를 'For a while'(잠시 동안)로 표현한 문장, 옛 시험 문법(lest ~ should, cried with delight that…).
- 용어가 옛 학교문법(서술문, 기원문, 복합 인칭 대명사 = 재귀대명사, 복합 관계 대명사) → 지금 교과서 용어와 병기 필요.
- 편집 원본(.pub)도 있음. 2권 .pub 에도 알려진 오류가 그대로 있어 "고친 판"은 아님. 1권 .pub 는 변환이 그림 위주라 대조 불가.

    길이 1.15배) + 부정 뒤집힘/접두 반의어 0점. 한계: 맞는 표현의 약 60%만 인정 목록에 있음(92/229 놓침, 사장님 수용),

## 4. 제품·기술 조사 결론

- 빌려올 것: 클래스카드 '성분 찾기'(단어 칩 탭 → 라벨, AI 없이 100% 자동 채점)·'보고 떠올리기→배열→타이핑' 사다리·부모 성적표
  카톡 전송 / 말해보카 한→영 카드 배열 + 한 줄 오답 이유 + 개념 카드 링크 / 듀오링고 허용 답 목록 + "내 답도 맞아요" 신고
  (거짓 오답이 신고의 72%) + 타일↔키보드 전환 / Quill 식 '틀린 위치 힌트 → 2~3회 다시 쓰기 → 정답+이유' / 3800제식 유형 사다리
  (선택 → 단답 → 문장 완성 → 서술형 영작) + 숙달하면 종료 / 산타식 오답노트·약점 기반 순서 / 밀크T식 학부모 한 장 요약.
- 피할 것: 음성 인식으로 문법 채점(스픽 리뷰: 어순을 뒤집어도 만점) · 항상 켜진 단어 은행 · 긴 영상 수동 학습 · 무조건 많은 양 ·
  말하기를 진도 필수 조건으로(카톡 인앱에서 막힘) · 하트/광고식 게이미피케이션.
- 한국 학습자·학부모 기대: 문법 용어와 명시적 설명, 내신 서술형 대비(시험 모드는 대소문자·마침표·철자까지), 충분한 문제량 +
  오답노트, 부모가 볼 기록(카톡), 짧게 매일, 한국인 빈출 오류(관사·3인칭 -s·be동사·어순)를 짚는 피드백.
- 채점 권장(하이브리드): 정규화+허용 목록 → 오답 패턴 사전 → 판정 캐시 → 틀린 위치 표시·재시도 → (목록 밖만) LLM → 사람 검토 →
  허용 목록 승격. LLM 1회 약 4~8원(Sonnet 5 $2/$10 per MTok, Haiku 4.5 $1/$5, Opus 5.5 $4/$20; Haiku 4.5 은 2026-10-15 이후
  은퇴 예정 표기). 허용 목록 사전 생성은 Batch(50% 할인)로 수만 원 수준. LLM 은 오답 검출이 약함(연구) → 1순위로 쓰지 말 것.
- 음성: 말하기는 선택 기능. 넣는다면 Azure 발음평가(대본형) 5초 1회 약 2~2.5원, 월 5시간 무료. 카톡 인앱은 음성 인식 불가.
- 간격 반복: 1차 고정 간격표, 기록이 쌓이면 ts-fsrs. 스케줄 단위는 '문법 포인트 × 과제 유형', 출제는 매번 다른 문장.
- 모바일 입력: autocorrect/spellcheck off, 둥근 따옴표 정규화, 한글 섞이면 '영어 자판으로' 안내, IME 조합 중 Enter 무시, 탭 타일.

## 5. 사장님 규칙 (어기면 안 됨)

1. 과정 구조(레슨 순서·제목·레슨 추가/삭제)는 사장님 승인 없이 못 바꿈. 원래 목차가 기준. 목차-본문 불일치는 보고하고 결정받음.
2. 한 과정의 모든 레슨은 같은 학습 방식(같은 단계·같은 화면). 특별 화면 금지. 이상한 레슨은 데이터를 맞춰 표준 단계 안으로.
3. 교재는 정답지가 아님: 틀린 영어·오역·틀린 정답은 고침. 단 교재 시대의 사실(토요일 수업 등)은 오류가 아님(그대로).
4. 영어 글을 바꾸면 그 문장 음성을 같은 작업에서 새로 만듦(해시 키). 생성 → R2 → 푸시 순서.
5. 로마자 한국어 낱말은 한국어처럼 들려야 함(IPA 방식, 사장님이 샘플 듣고 고름). 발음 방식 변경은 샘플을 먼저 들려 드림.
6. 공개 파일에 유료 본문 0건(유출 검사 통과가 출시 조건). 무료 체험 범위도 이 규칙 안에서.
7. UI 에 음성 출처 문구 금지. CNN·GVA 는 손대지 않음. 법률·결제·저작권과 푸시·배포는 사장님 몫(설계는 '어떤 이용권이 여는가'만 결정 질문으로).
8. 검사는 일부러 망가뜨려 실패하는지 증명한 뒤에만 PASS. 유료 레슨도 검사. 감사가 찾은 문제는 하나하나 다 고침.
   보고서가 인정한 한계는 반드시 번호 붙은 단계의 구체 작업으로 배정.
9. 같은 AI 가 쓰고 점검한 것은 '독립 검수 아님'이라고 밝히고, 사장님이 폰으로 1분 안에 확인할 방법을 줌.
10. 작업은 보통 '수정 세션'이 하고 '점검 세션'이 숫자로 다시 확인. 시간 추정은 이 프로젝트에서 잰 속도로
    (예: 7단계 약 7.5시간 · 내용 재검토 시간당 약 4,500줄 · STUDENT 쪽 화면 검사 쪽당 약 200초 · 브라우저 동시 2~3개).
11. 사장님은 비개발자. 결정은 제품 질문(무엇을 만들고, 무엇을 내보내고, 무엇을 뺄지)만. 작업 순서 고르기는 묻지 않음.
