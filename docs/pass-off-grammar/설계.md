## 3. 레슨 5단계 (모든 레슨 공통 — 특별 화면 금지)

| 단계 | 하는 일 | 채점·끝 조건 | 데이터 |
|---|---|---|---|
| ① 예문 떠올리기(Pass-Off Sentences) | 한국어 → 🎙️ 먼저 말해 보기(선택) → "영어 보기"(2초 뒤 켜짐) → 영어·소리 확인. 최대 8문장. STUDENT 꼬리표 | 채점 없음. 모두 한 번씩 보면 끝 | `anchors` 블록: en, ko, focus 범위, studentRef{lesson, exact\|adapted} |
| ② 규칙 1~3분 | 발견 질문 1 → 설명 카드(규칙 3~5줄 · 표 1 · 한국어와 다른 점 · ✗/✓ 흔한 실수 · 풀이 예시 1~2 · 용어 병기) → 규칙 확인 1 | 발견 질문은 기록만. 규칙 확인은 틀리면 해당 줄을 짚고 다시 | `rule` 블록 |

| ④ 영작(Application Sentences, 세트 단위) | 한국어(+조건 칩: 'it을 써서', '(who)', '수동태로') → 타이핑 또는 🎙️ 마이크로 말해서 영작하기(글자로 채워짐, 고칠 수 있음) | 시도 전 정답 잠금. 틀리면 사다리: ① 틀린 자리(빠짐 네모 · 틀림 물결 · 남음 취소선) → ② 태그별 단서 + 첫 글자 → ③ 단어 타일(문법 방해 타일 2) → ④ 정답·규칙·소리. 틀리거나 도움 받은 문장은 3~5문장 뒤 재출제, 세트의 모든 문장을 한 번씩 스스로 맞혀야 끝(3번 재출제에도 못 맞히면 '내일 1순위'). 첫날은 타일 기본 허용 | `drill` 블록 produce 항목 |
| ⑤ 마무리 | 처음 보는 문장 2(배운 문법 태그만 · GRAMMAR I·II 의 검수된 문장 중 맞는 것 먼저, 없으면 새로) → 규칙 확인 1 → 내 문장 틀 1(채점 없음, 기기에만 저장) | 전이 문장은 ④와 같이 판정 | `drill` 블록 transfer · `frame` |

- 교재 과제 유형 → 단계: 한→영 영작·지정 요소 영작·관계사 힌트·yes/no 단답·능동↔수동·직접→간접·빈칸·시제 일치·바꿔쓰기·불규칙동사표·목록(복수형·서수·대명사표) = ④ produce. 밑줄·동그라미·품사·형식·문장 종류·시제 이름·용법·조동사 뜻·접속사 분류 = ③. 영→한 해석 = ③ 의 "뜻이 다른 번역 3개 중 고르기".

## 4. 날을 넘기는 복습 — **초안**(D8: 공통 학습 엔진 설계가 나오면 그쪽이 우선)

- 기록 단위는 문항. 날짜 경계는 **한국시간 오전 4시**(서버 시각).
- 일정: 1일 레슨(판정 안 함) → 2일 "확인"(교재 Review 시험형: 다 풀고 결과 한꺼번에, 서술형 두 줄 점수, 틀린 문장은 즉시 사다리) → 4일 R2(여러 레슨 섞기, 헷갈리는 짝 가까이) → 8일~ R3 → 통과 → 21 · 60 · 120일 유지(레슨당 2~3문항, 매번 다른 문장).
- **문장 통과**: 서로 다른 날 3번, 도움 없이 첫 시도 정답(첫날 제외 · 힌트·타일·정답 보기 사용 제외). 그중 한 번은 첫날로부터 6일 이후. 마지막 시도도 정답. 요소 문항은 2번.
- **레슨 통과**: 핵심 · 전이 2 · 요소 모두 통과 → 구성도 동그라미 채움. 도전 문장은 그 문법 레슨 학습 뒤 조건에 포함.
- 유지 확인에서 틀리면 그 문장만 R1 로, 레슨은 '복습 필요'(붉은 점).
- 하루 복습 상한 30(출발값 · 시안 실측으로 조정), 재학습 중 문장 60 초과면 "복습 먼저" 권유(잠금 아님), 3일 이상 쉬면 "복습 10문장" 복귀 코스.
- 같은 날 두 기기 기록이 충돌하면 틀린 쪽을 씀.
- 오답노트(레슨별 틀린 문장·유형, "지금 다시 풀기"), R1 첫 시도 60% 미만 레슨은 R2 전에 보충 설명 카드.
- "내 답도 맞아요" = 보류(맞음·틀림 모두 아님, 다음 날 재출제), 주 1회 수정 세션이 판정 → 계획 파일로 허용 목록 반영 → 관문 4.
- 통과한 문장의 선택 "빠르게 말하기"(시간만 기록).
- 대주제 끝 "구성도 다시 채우기"(빈 구성도에 레슨 이름 칩 + 칸마다 규칙 한 줄 고르기 + 대표 문장 1), 권 끝에는 권 전체. 틀린 칸은 복습으로.
- 오늘 할 일 페이지: 서버가 이용권 확인 → 진도 읽기 → 오늘 문항만 props 로 전달. **유출·잠금 탐침 대상에 반드시 추가.**
- 90일 모의실험 3유형(매일 · 주 3회 · 7일 쉼)과 날짜 경계 일부러 바꾸기 시험.

- **partial 은 정답이 아님**(기능어 하나 차이도 사다리로). 오타는 5글자 이상 내용어 1글자만 "맞음(오타 표시)", 목표 낱말·기능어는 엄격.
- 접두 반의어 규칙 과민(interesting → in+teresting) 예외 목록과, 이 과정 정답·오답 대조 검사.
- 마이크: `VoiceSpeakingTester` 동작은 바꾸지 않고, 결과 글자를 입력칸에 채워 위 채점기로 판정(GRAMMAR I 과 같은 흐름). 다른 정답 비교가 필요하면 새 선택 prop 을 더하되 prop 이 없을 때 기존 동작 그대로.
- 시험형("확인" · 대주제 점검): 서술형 두 줄 점수("문법 정답 10/12 · 서술형 기준 8/12" + 대문자·마침표·철자 이유 칩), 통과는 문법 정답만.
- 출시 전 증거(모두 일부러 깨기로 실패 증명):
  1. 역번역 대조 — 다른 일꾼이 한국어 제시문과 레슨 제목만 보고 영작한 답을 채점기로 대조(912문장 전부). 제시문이 목표 영어를 가리키는지.
  2. 가린 인정률 — 목록을 안 본 일꾼이 쓴 맞는 답 3개 × 100문항이 정답 처리되는 비율.
  3. 교재 원문 오류 문장(예: "I have just have lunch.")을 틀린 대조로 넣어 오답 판정되는지.
  4. GRAMMAR I·II 판정 변화 0(`compare-grading.cjs`).
