# PASS-OFF GRAMMAR — 레슨 데이터 형식 (v1.1, 2026-09-27)

내용을 만드는 쪽(이 세션)과 코드를 만드는 쪽(옆 세션)이 **같은 모양**을 쓰기 위한 약속입니다.
바꿀 때는 이 파일을 고치고 버전을 올린 뒤 상대 세션에 알립니다. 필드 이름은 영어, 값(설명·번역)은 한국어입니다.

- v1.1(코드 단계 A): 아래 "파일 위치" 의 과정 목록 · 유료 STUDENT 보충 문항 방식을 코드 쪽이 정함.

## 파일 위치

- 레슨: `content/lessons/passoff-grammar/pgNN-M.json` (예: `pg02-1.json`) — 레슨 67개, `variant: "main"` 만.
- 과정 목록: `content/courses/passoff-grammar.json` — **손으로 쓰지 않는다.** `node scripts/buildPassoffIndex.mjs`(prebuild · predev 가 먼저 돌림)가 레슨 폴더에 **실제로 있는** 파일로 만든다: 대주제마다 그룹 하나(`title`·`label` 둘 다 = 레슨의 `label`), 레슨 순서 pg01-1 · pg01-2 · …. 무료 두 레슨(pg01-1 · pg01-2)이 첫 두 카드가 아니거나, 파일 이름과 `id` 가 다르거나, 한 대주제의 `label` 이 레슨마다 다르면 만들기를 거절한다.
- 무료 체험에서 가릴 유료 STUDENT 문항: 레슨 파일(pg01-1.json)에 `paidStudent: true` 로 써도 된다 — `buildPassoffIndex.mjs` 가 그 문항을 떼어 `content/private/passoff-grammar/pg01-1.paid.json`(서버 전용)으로 옮기고, 이용권이 이 과정을 열 때만 서버가 제자리에 붙인다(`src/lib/passoffContent.ts`). 무료 쪽에는 "이용권이 있으면 N문장 더"(N = 서로 다른 `en` 수).
  - 보충 파일을 직접 고쳐도 되고, 레슨 파일에 같은 id 로 `paidStudent: true` 를 다시 넣으면 새것이 이긴다. `paidStudent` 를 빼고 레슨 파일에 두면 보충 파일에서 빠진다. 문항을 아예 없애려면 보충 파일에서도 지운다.
  - 레슨 파일을 커밋하기 전에 `node scripts/buildPassoffIndex.mjs` 를 돌려 **떼어 낸 상태로** 커밋한다(떼기 전 파일이 저장소에 있으면 기존 유출 도구가 그 유료 문장을 공개로 보고 건너뛴다).
  - `node scripts/checkPassoffFreeLeak.mjs` — 무료 두 레슨의 파일과 무료 소리 키에 유료 STUDENT 문장(표시를 안 한 것 포함)이 남으면 FAIL.

## 레슨 파일

기존 `Lesson` 형식(types.ts:173-215)의 필수 필드를 그대로 채운다.
- `id`, `course: "passoff-grammar"`, `series: "pg"`, `variant: "main"`, `pairId: null`
- `title`(목차 동그라미 글자), `label`(대주제 "TOPIC 2. 동사의 현재형"), `menuLabel`("2-1. Be동사의 현재형")
- `unit`(대주제 번호), `part`(권 1~3), `order`(고리 번호)
- `audio: []`, `video: []`, `legacyPath: null`, `legacyEncoding: null`
- `blocks`: 아래 5종

```jsonc
{
  "id": "pg02-1", "course": "passoff-grammar", "series": "pg", "variant": "main", "pairId": null,
  "title": "Be동사의 현재형", "label": "TOPIC 2. 동사의 현재형", "menuLabel": "2-1. Be동사의 현재형",
  "unit": 2, "part": 1, "order": 1,
  "audio": [], "video": [], "legacyPath": null, "legacyEncoding": null,
  "subtitle": "be 동사의 현재형 : am / is / are",          // 교재 본문 소제목(있을 때)
  "grammarTags": ["be-present"],                         // 이 레슨의 목표 문법 태그(아래 태그 규칙)
  "blocks": [ /* anchors, rule, drill, frame 순서 */ ]
}
```

### 1) `anchors` — ① 예문 떠올리기

```jsonc
{ "type": "anchors",
  "items": [
    { "id": "pg02-1:a1",
      "en": "I am eleven years old.",
      "ko": "나는 열한 살이다.",
      "focus": ["am"],                                   // 강조할 낱말(여러 낱말 덩어리는 "had better" 처럼 한 문자열)
      "studentRef": { "lesson": "s1-2", "kind": "adapted" },  // exact | adapted, 없으면 필드 생략
      "bookRef": { "book": 1, "page": 10, "where": "passOff 1) item 1" } } ] }
```
- 최대 8개. `studentRef.kind = "exact"` 는 STUDENT 문장과 글자까지 같을 때만(링크 대상).
- STUDENT 와 같은 문장은 `en`·`ko` 모두 STUDENT 판(사장님 결정).

### 2) `rule` — ② 규칙

```jsonc
{ "type": "rule",
  "discovery": { "anchorIds": ["pg02-1:a1","pg02-1:a2","pg02-1:a3"],
                 "question": "am / are / is 는 무엇에 따라 바뀔까요?",
                 "options": ["주어", "시제", "문장 길이"], "answer": 0,
                 "why": "주어가 I 면 am, you·복수면 are, 3인칭 단수면 is 입니다." },
  "title": "am · are · is 는 주어에 따라 바뀝니다",
  "points": ["…", "…", "…"],                           // 3~5줄, 줄당 40자 안팎
  "table": { "columns": ["주어", "be동사"], "rows": [["I","am"],["you · we · they","are"],["he · she · it","is"]] },  // 선택
  "koDiff": "'~이다'는 누가 주어든 그대로지만, be동사는 주어에 맞춰 모양이 바뀝니다.",
  "mistakes": [ { "wrong": "She are tired.", "right": "She is tired.", "why": "She 는 3인칭 한 명" } ],
  "worked": ["그녀는 → She", "3인칭 한 명", "→ is", "She is tired."],   // 풀이 예시 단계(선택)
  "terms": [ { "now": "평서문", "book": "서술문" } ],   // 옛 용어 병기(있을 때)
  "check": { "question": "'He ___ my teacher.' 빈칸에 맞는 것은?", "options": ["am","are","is"], "answer": 2,
             "why": "He 는 3인칭 단수", "pointIndex": 0 } }
```

### 3) `drill` — ③ 형태 찾기 · ④ 영작 · ⑤ 마무리의 전이 문장

```jsonc
{ "type": "drill",
  "select": [   // ③ 형태 찾기 (4~6개; 초과분은 "reserve": true 로 복습 풀)
    { "id": "pg02-1:s1", "kind": "select",
      "instruction": "be동사를 모두 누르세요",
      "tokens": ["They", "are", "pleased", "to", "find", "her", "."],   // 덩어리는 한 토큰("as soon as")
      "answer": [1],                                      // 정답 토큰 번호들
      "optional": [],                                     // 골라도 감점 안 하는 토큰(예: 관사)
      "labels": null,                                     // 라벨이 필요하면 ["1인칭","2인칭","3인칭"]
      "labelAnswer": null,                                // 라벨 정답(토큰별이면 배열)
      "why": "They 는 3인칭 복수라 are.",
      "bookRef": { "book": 1, "page": 12, "where": "review 1 item 1" } },
    { "id": "pg02-1:s2", "kind": "choice",
      "instruction": "밑줄 친 대명사는 몇 인칭인가요?",
      "sentence": "It makes me happy.", "underline": ["It"],
      "options": ["1인칭","2인칭","3인칭"], "answer": 2, "why": "It 은 3인칭 단수",
      "bookRef": { "book": 1, "page": 7, "where": "review 1 item 7" } },
    { "id": "pg02-1:s3", "kind": "short",
      "instruction": "동사의 원형을 쓰세요", "sentence": "My sister likes all kinds of animals.",
      "answer": ["like"], "why": "likes 에서 -s 를 뗀 원형", "bookRef": { "book": 1, "page": 12, "where": "review 2 item 1" } }
  ],
  "produce": [  // ④ 영작 (Application Sentences). 세트는 코드가 문장 길이로 나눔(약 6분)
    { "id": "pg02-1:p1",
      "ko": "그녀는 오늘 피곤하다.",
      "condition": null,                                  // 조건 칩: "it을 써서" · "(who)" · "수동태로" · "간접화법으로" …
      "promptEn": null,                                   // 영어로 주어지는 문항(능동→수동, yes/no 질문 등)이면 영어 원문
      "en": "She is tired today.",                        // 모범 답(화면·소리)
      "accept": ["She's tired today.", "She is tired today"],   // 허용 답(정규화 전 원형). 모범 답은 자동 포함
      "targets": [["is", "'s"]],                          // 목표형 any-of 묶음들 — 하나라도 없으면 틀림
      "errorPatterns": [ { "match": "She are", "hint": "주어 She 는 3인칭 한 명이에요. be동사 모양은?" } ],
      "tags": ["be-present", "3sg"],                      // 이 문장이 쓰는 문법 태그(섞기·도전 판정용)
      "challenge": false,                                 // 아직 안 배운 문법이 섞였으면 true + challengeTags
      "challengeTags": [],
      "paidStudent": false,                               // 무료 체험에서 가릴 유료 STUDENT 문장이면 true
      "studentRef": null,
      "bookRef": { "book": 1, "page": 10, "where": "application 1) item 8", "reviewWhere": "review 3 item 4" },
      "fix": null }                                       // 교재에서 고쳤으면 { "from": "원문", "kind": "english_grammar", "why": "…" }
  ],
  "transfer": [ // ⑤ 처음 보는 문장 2개 — produce 와 같은 모양 + source
    { "id": "pg02-1:t1", "ko": "그 가게는 일요일에 닫혀 있다.", "en": "The shop is closed on Sundays.",
      "accept": ["The shop's closed on Sundays."], "targets": [["is","'s"]], "tags": ["be-present"],
      "source": "new" }                                   // "new" | "grammar1:gh1-007#3" | "grammar2:gh2-010#5"
  ] }
```

### 4) `frame` — ⑤ 내 문장

```jsonc
{ "type": "frame", "id": "pg02-1:f1", "template": "I am ___ years old.", "ko": "나는 ___살이다." }
```

## 문항 id 규칙

`<레슨 id>:<종류 글자><번호>` — a(anchor) · s(select/choice/short) · p(produce) · t(transfer) · f(frame). 한 번 붙인 id 는 **바꾸지 않는다**(학생 기록의 열쇠). 문항을 빼면 번호를 비워 두고 재사용하지 않는다.

## 태그 규칙

영어 소문자·하이픈. 레슨의 `grammarTags` 가 그 레슨의 목표이고, 문장의 `tags` 에 그 레슨보다 뒤 레슨의 목표 태그가 있으면 `challenge: true`. 태그 목록은 `태그.json`(이 세션이 만듦)에 레슨 순서대로.

## 음성

- 소리 내는 글 = anchors·produce·transfer 의 `en`(화면에 보이는 그대로). 한국어는 재생하지 않음.
- 로마자 한국어 낱말은 레슨 파일에 `koreanWords: ["Chuseok", …]` 로 적어 두고, 코드 쪽이 `lessonSpeechForm.ts` 에 IPA 행을 넣는다.
- 동형이음어(read[red])는 문항에 `speakAs: "red"` 처럼 적는다.
