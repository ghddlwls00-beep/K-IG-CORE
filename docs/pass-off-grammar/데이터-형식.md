# PASS-OFF GRAMMAR — 레슨 데이터 형식 (v1.3, 2026-09-27)

내용을 만드는 쪽(이 세션)과 코드를 만드는 쪽(옆 세션)이 **같은 모양**을 쓰기 위한 약속입니다.
바꿀 때는 이 파일을 고치고 버전을 올린 뒤 상대 세션에 알립니다. 필드 이름은 영어, 값(설명·번역)은 한국어입니다.

- v1.1(코드 단계 A): 아래 "파일 위치" 의 과정 목록 · 유료 STUDENT 보충 문항 방식을 코드 쪽이 정함.
- v1.2(1권 검사 뒤): `labelAnswer` 는 라벨 **글자**(번호 아님, `passoffTypes.ts` 와 같음) · 오답 패턴 규칙과 `literal` · `challenge` 와 태그를 맞추는 규칙 · 검사 도구 `검사/check-lessons.cjs`.
- v1.3(1권 점검 · 수정 뒤): 문항에 둘 수 있는 필드 목록(아래 "필드 목록" — 목록 밖 필드는 검사가 막음) · `fix.fromKo` · 앵커의 `promptEn` · 오답 패턴은 **낱말 경계** 비교 · **앞 단계가 ④ 정답을 먼저 보여 주지 않기** · ⑤ 처음 보는 문장 · 힌트가 정답을 그대로 말하지 않기.

| `fix` | `from`(옛 영어·문장) · `fromKo`(옛 한국어) · `field`("en" · "ko" · "en+ko" · "sentence" · "underline" …) · `kind` · `why` |
| `errorPatterns[]` | `match` · `hint` · `literal` |

- **화면에 안 나오는 기록용**: `source` · `koSource` · `note` · `challengeNote` · `bookRef` · `fix`(원문 대조표에만).
- `source`: 교재에 인쇄된 과제가 아닐 때. `"new"`(이 과정에서 만듦 — ③ 에서는 "과제를 새로 만들었고 문장은 bookRef 의 교재 문장"), `"student:s3-3#1"`, `"grammar1:gh1-007#3"`, `"grammar2:gh2-010#5"`.
- `koSource`: 한국어를 어디서 가져왔나(`review …` · `student …` · `grammar …` · `new …` 로 시작하는 자유 글).
- 앵커 `promptEn`: 대답 레슨(pg05-2 등)의 영어 질문. 화면에서 한국어 위에 보이고, **소리는 내지 않는다**(소리는 `en` 만).
- 없앤 것: `reject`(→ `errorPatterns` 의 `literal`), `koFix`(→ `fix.fromKo`).

## 앞 단계가 정답을 먼저 보여 주지 않기 (v1.3)

① 앵커 문장은 ④ 에서 다시 쓰게 **일부러** 보여 준다(교재 Pass-Off 문장). 그 밖의 ④ 문장은 ④ 에서 처음 떠올려야 한다. 그래서:
- ③ 형태 찾기의 `sentence`/`tokens` 가 앵커가 아닌 ④ 문장의 `en` 과 같으면 안 된다. 교재 Review 과제가 그 문장을 쓰면 그 문항은 `"reserve": true`(날을 넘기는 복습에서 ④ 뒤에 나옴)로 돌리고, 같은 기술을 묻는 대신 문항을 다른 문장(앵커 · 새 문장)으로 만들어 레슨 안 4~6개를 채운다.
- ② 설명 카드의 `worked` · `mistakes[].right` 도 앵커가 아닌 ④ 문장을 쓰지 않는다(앵커나 새 문장으로).
- ⑤ 처음 보는 문장(transfer)은 레슨의 다른 곳(①~④ · 설명 카드)에 나오지 않아야 한다.
- 오답 패턴의 `hint` 는 모범 답을 그대로 말하지 않는다(스스로 고치게).

## 파일 위치

- 레슨: `content/lessons/passoff-grammar/pgNN-M.json` (예: `pg02-1.json`) — 레슨 67개, `variant: "main"` 만.
- 과정 목록: `content/courses/passoff-grammar.json` — **손으로 쓰지 않는다.** `node scripts/buildPassoffIndex.mjs`(prebuild · predev 가 먼저 돌림)가 레슨 폴더에 **실제로 있는** 파일로 만든다: 대주제마다 그룹 하나(`title`·`label` 둘 다 = 레슨의 `label`), 레슨 순서 pg01-1 · pg01-2 · …. 무료 두 레슨(pg01-1 · pg01-2)이 첫 두 카드가 아니거나, 파일 이름과 `id` 가 다르거나, 한 대주제의 `label` 이 레슨마다 다르면 만들기를 거절한다.
- 무료 체험에서 가릴 유료 STUDENT 문항: 레슨 파일(pg01-1.json)에 `paidStudent: true` 로 써도 된다 — `buildPassoffIndex.mjs` 가 그 문항을 떼어 `content/private/passoff-grammar/pg01-1.paid.json`(서버 전용)으로 옮기고, 이용권이 이 과정을 열 때만 서버가 제자리에 붙인다(`src/lib/passoffContent.ts`). 무료 쪽에는 "이용권이 있으면 N문장 더"(N = 서로 다른 `en` 수).
  - 보충 파일을 직접 고쳐도 되고, 레슨 파일에 같은 id 로 `paidStudent: true` 를 다시 넣으면 새것이 이긴다. `paidStudent` 를 빼고 레슨 파일에 두면 보충 파일에서 빠진다. 문항을 아예 없애려면 보충 파일에서도 지운다.
  - 레슨 파일을 커밋하기 전에 `node scripts/buildPassoffIndex.mjs` 를 돌려 **떼어 낸 상태로** 커밋한다(떼기 전 파일이 저장소에 있으면 기존 유출 도구가 그 유료 문장을 공개로 보고 건너뛴다).
  - `node scripts/checkPassoffFreeLeak.mjs` — 무료 두 레슨의 파일과 무료 소리 키에 유료 STUDENT 문장(표시를 안 한 것 포함)이 남으면 FAIL.

## 레슨 파일

기존 `Lesson` 형식(types.ts:173-215)의 필수 필드를 그대로 채운다.
- `id`, `course: "passoff-grammar"`, `series: "pg"`, `variant: "main"`, `pairId: null`
- `title`(목차 동그라미 글자), `label`(대주제 "TOPIC 2. 동사의 현재형"), `menuLabel`("2-1. Be동사의 현재형")
- `unit`(대주제 번호), `part`(권 1~3), `order`(고리 번호)
- `audio: []`, `video: []`, `legacyPath: null`, `legacyEncoding: null`
- `blocks`: 아래 5종

```jsonc
{
  "id": "pg02-1", "course": "passoff-grammar", "series": "pg", "variant": "main", "pairId": null,
  "title": "Be동사의 현재형", "label": "TOPIC 2. 동사의 현재형", "menuLabel": "2-1. Be동사의 현재형",
  "unit": 2, "part": 1, "order": 1,
  "audio": [], "video": [], "legacyPath": null, "legacyEncoding": null,
  "subtitle": "be 동사의 현재형 : am / is / are",          // 교재 본문 소제목(있을 때)
  "grammarTags": ["be-present"],                         // 이 레슨의 목표 문법 태그(아래 태그 규칙)
  "blocks": [ /* anchors, rule, drill, frame 순서 */ ]
}
```

### 1) `anchors` — ① 예문 떠올리기

```jsonc
{ "type": "anchors",
  "items": [
    { "id": "pg02-1:a1",
      "en": "I am eleven years old.",
      "ko": "나는 열한 살이다.",
      "focus": ["am"],                                   // 강조할 낱말(여러 낱말 덩어리는 "had better" 처럼 한 문자열)
      "studentRef": { "lesson": "s1-2", "kind": "adapted" },  // exact | adapted, 없으면 필드 생략
      "bookRef": { "book": 1, "page": 10, "where": "passOff 1) item 1" } } ] }
```
- 최대 8개. `studentRef.kind = "exact"` 는 STUDENT 문장과 글자까지 같을 때만(링크 대상).
- STUDENT 와 같은 문장은 `en`·`ko` 모두 STUDENT 판(사장님 결정).

### 오답 패턴 (`errorPatterns`) 규칙 — v1.2

채점기는 대소문자·문장부호를 무시하고 축약형을 양쪽으로 펴서 비교합니다(GRAMMAR I·II 와 같은 느낌; 마이크 답의 쉼표는 음성 인식기가 찍은 것이라 믿을 수 없음). 그래서:
- 보통 패턴(`{ "match", "hint" }`)은 **틀린 답 속의 한 조각**이고, 채점기와 같은 정규화 뒤 **낱말 경계로** 비교합니다(부분 문자열 아님 — "is your" 는 "is yours" 에 안 걸림). 같은 정규화로 모범 답·허용 답 어디에도 들어 있으면 안 됩니다. 들어 있으면 그 정답 조각을 공유하는 모든 오답에 엉뚱한 힌트가 뜹니다. 예: "In Saudi," 는 "In Saudi Arabia" 에 걸림 → "in Saudi one" 처럼 틀린 곳까지 적습니다.
- **문장부호만 다른 오답은 패턴으로 만들지 않습니다**(예: 계속적 용법의 쉼표 "songpyeon which"). 쉼표는 규칙 카드 · 풀이 예시로 가르칩니다.
- 축약형만 다른 오답(짧은 대답 "Yes, it's." · "Is not this a hat?")은 축약형을 펴면 정답과 같아져 보통 패턴이 안 됩니다. 이런 것만 **`"literal": true`** 로 **틀린 답 전체**를 적습니다: `{ "match": "Yes, it's.", "hint": "짧은 대답 끝에서는 줄이지 않아요: Yes, it is.", "literal": true }`. 채점기는 허용 답보다 **먼저**, 대소문자·문장부호만 무시하고 축약형은 펴지 않은 채 **답 전체가 같을 때만** 틀림으로 봅니다("Yes, it's a desk." 는 해당 없음).

### 도전(`challenge`)과 태그를 맞추는 규칙 — v1.2

- 문장의 `tags` 에 이 레슨보다 **뒤** 레슨의 목표 태그(base 제외)가 있으면 `challenge: true` 이고 그 태그를 `challengeTags` 에 적습니다.
- 그 문법 없이도 같은 뜻의 문장을 만들 수 있거나 목표가 아닌 곁가지면, `challenge` 를 켜지 말고 그 태그를 `tags` 에서 뺍니다.
- `challenge: false` 인데 `challengeTags` 가 있으면 안 됩니다.

### 검사 도구

`node docs/pass-off-grammar/검사/check-lessons.cjs` — 형식 · id · 정답 번호 · 목표형 · 오답 패턴 · 태그/도전 · STUDENT exact 문장 글자 일치(한국어 포함) · 금지 문구 · 영어 속 한글 · 교재 문장 빠짐 · 교재 오류 후보 판정을 봅니다. 무료 레슨에서 떼어 낸 유료 STUDENT 문항(`content/private/…/*.paid.json`)은 제자리에 되돌려 넣고 봅니다. 문제 0 이어야 커밋합니다. `--selftest` 는 일부러 깬 복사본 18가지를 모두 잡아야 통과합니다(검사가 실패할 수 있음을 증명). 그중 "교재 문장 빠짐"은 한 가지가 아닙니다. 레슨 어디에도 다시 안 나오는 교재 문장을 하나씩 전부 빼 보고, 빠짐으로 잡힌 수를 셉니다(1권: 66/66).

## 문항 id 규칙

`<레슨 id>:<종류 글자><번호>` — a(anchor) · s(select/choice/short) · p(produce) · t(transfer) · f(frame). 한 번 붙인 id 는 **바꾸지 않는다**(학생 기록의 열쇠). 문항을 빼면 번호를 비워 두고 재사용하지 않는다.

## 태그 규칙

영어 소문자·하이픈. 레슨의 `grammarTags` 가 그 레슨의 목표이고, 문장의 `tags` 에 그 레슨보다 뒤 레슨의 목표 태그가 있으면 `challenge: true`. 태그 목록은 `태그.json`(이 세션이 만듦)에 레슨 순서대로.

## 음성

- 소리 내는 글 = anchors·produce·transfer 의 `en`(화면에 보이는 그대로). 한국어는 재생하지 않음.
- 로마자 한국어 낱말은 레슨 파일에 `koreanWords: ["Chuseok", …]` 로 적어 두고, 코드 쪽이 `lessonSpeechForm.ts` 에 IPA 행을 넣는다.
- 동형이음어(read[red])는 문항에 `speakAs: "red"` 처럼 적는다.
