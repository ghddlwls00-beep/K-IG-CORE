## 0. 🔴 먼저 — 재추출로 덮어쓰면 안 됩니다

`scripts/extract.mjs:465`는 레슨 JSON을 **통째로 덮어씁니다**.

```js
fs.writeFileSync(path.join(outDir, `${lesson.id}.json`), JSON.stringify(lesson, null, 2), "utf-8");
```

그리고 `extract.mjs`는 `readingSentences`와 `readingVocabulary`를 **만들지 않습니다**(소스 내 언급 0건).
이 두 필드는 `build-reading-aligned.mjs`·`build-reading-voca.mjs`가 추출 이후에 얹은 것입니다.

**따라서 `content/`에 대고 재추출하면 READING 256개 레슨의 문장 정렬과 어휘 카드 7,168장이
전부 사라집니다.** READING 과정이 통째로 죽습니다.

추출 이후 손으로 다듬은 것이 이만큼 쌓여 있습니다.

```
603ce71  STUDENT 81레슨 순서 재배열 + 한국어 1:1 정렬
51f032f  READING 256레슨 1:1 문장 정렬 + 영구 ID
4502e71  READING 어휘 빌더 전면 개편 (레슨당 14개)
87abed0  READING 어휘 카드 한국어 뜻 256레슨
ce95afb  LISTENING 200강 → 20챕터 재편
37d2a26  KIG-002 READING 170파일
a088969  과정 인덱스 5파일
```

**아카이브는 덮어쓰기 대상이 아니라 정답지입니다.** 대조해서 깨진 값만 골라 고칩니다.

### 안전한 절차

1. 레포를 **짧은 경로에 복사**합니다(경로 길이 문제 회피). 예: `C:\kigextract`
2. 거기서 `--no-media` 로 추출합니다. 원본 `content/`는 건드리지 않습니다.
3. 두 트리를 **필드 단위로 비교**합니다.
4. 필요한 값만 현재 `content/`에 이식합니다.

```bash
# 1) 복사본에서만 추출
node scripts/extract.mjs --src "<아카이브 경로>" --no-media --dry-run   # 먼저 건수 확인
node scripts/extract.mjs --src "<아카이브 경로>" --no-media

# 2) 비교는 별도 스크립트로 (대조 후 작성)
```

`--media`로 돌리면 `public/audio/<course>/`를 다시 추출해 R2에 올린 것과 어긋날 수 있으므로
**반드시 `--no-media`** 를 씁니다.

## 2. Tier 2 — 신호가 못 보는 영역: 전수 대조

Tier 1은 "이상해 보이는 것"입니다. 정확성은 그것만으로 담보되지 않습니다.
아래는 **아카이브가 있을 때 기계적으로 전수 비교**해야 하는 분량입니다.

| 대상 | 분량 | 왜 전수인가 |
|---|---:|---|
| VOCA 단어·뜻 | **3,877** | 분류기가 360개를 의심했을 뿐, 나머지 3,517개는 아무도 확인하지 않았습니다 |
| READING 어휘 카드 | **7,168** | 레슨당 14장 × 256. 뜻·품사가 자동 생성분입니다 |
| READING 지문+번역 | **2,892** 문장 | KIG-002가 85레슨을 재생성했으므로 원본 대조가 필요합니다 |
| LISTENING 스크립트 | **2,518** 문장 | 기계 역번역 의심(KIG-003). 원본에 영어가 있으면 즉시 판정됩니다 |

## 4. 도착 당일 순서

1. 아카이브를 **읽기 전용**으로 마운트. 원본 폴더에 아무것도 쓰지 않습니다.
2. `랩자료모음/…/본사 Lab v1.01` 아래 폴더 구조 확인 —
   `LD` `reading` `phonics` `grammar1` `grammar2` `Student` `CNN`이 있는지.
3. **Tier 1의 "가장 먼저 볼 8건"** 을 수동 확인 — 15분이면 방향이 정해집니다.
4. 복사본에서 `--no-media --dry-run` → 추출 건수가 현재와 맞는지 대조.
5. 전수 비교 스크립트 작성·실행 → 차이 목록 산출.
6. 차이를 세 갈래로 분류: **원본이 맞음**(이식) / **현재가 개선됨**(유지) / **양쪽 다 문제**(사람 판단).
7. 이식 후 `npx tsc --noEmit`, `pnpm run build`, 그리고 **텍스트가 바뀐 만큼 음성 재생성**
   (`generate-azure-ava.mjs --dry-run` → 생성 → 업로드 → `pending: 0` 확인).

| gh1-040/088 정답 | 한국어 문제가 있으므로 영작 재작성 | 🟡 사람 필요 |
