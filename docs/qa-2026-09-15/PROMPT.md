# 다른 AI에게 그대로 붙여넣을 프롬프트

아래 블록 전체를 복사해서 새 AI 세션의 첫 메시지로 넣으세요.

---

당신은 이 레포(K-IG CORE, Next.js 16 App Router · React 19 · TypeScript · Tailwind 4 · Vercel 배포, 운영 https://k-ig-core.vercel.app)의 출시 전 결함을 수정하는 개발자입니다.

**먼저 `docs/qa-2026-09-15/README.md`를 전부 읽으세요.** 그 문서에 2026-09-15에 수행한 905개 레슨 전수 QA 감사 결과와, 확인된 41건의 결함(KIG-001 ~ KIG-036)이 심각도·정확한 `파일:줄번호`·증거 파일 위치·수정 지시·완료 조건까지 정리되어 있습니다. 증거 원본 데이터는 `docs/qa-2026-09-15/evidence/`, 재검증 스크립트는 `docs/qa-2026-09-15/scripts/`에 있습니다.

작업 규칙:
1. **KIG-001(P0)부터 시작**하세요. 잠긴 레슨 814개의 본문이 비로그인 HTML에 그대로 노출되는 문제이고, `src/app/student/[lesson]/page.tsx`가 정답 구현 패턴입니다.
2. 이슈 **하나씩** 처리합니다. 수정 → README에 적힌 완료 조건 실행 → 결과 보고 → 커밋(`fix(KIG-001): ...`). 다음 이슈로 넘어가기 전에 저에게 확인받으세요.
3. **검증하지 않은 것을 완료라고 하지 마세요.** 실행한 명령과 출력을 그대로 보여주세요.
4. 데이터 결함(KIG-002·003·004 등)은 원본 교재/원본 아카이브가 기준입니다. 데이터를 지워서 "해결"하지 마세요. 원본을 구할 수 없으면 그 사실을 알리고 해당 기능 비노출을 제안하세요.
5. 운영 데이터(Cloudflare R2 버킷, Vercel 환경변수)에 쓰기 금지. 로컬 검증은 README §5의 절차를 쓰세요.
6. `.env.local`과 `.vercel/`의 값은 절대 출력하거나 커밋하지 마세요.
7. `main`에 push하면 Vercel이 자동 배포됩니다. P0 수정 후에는 반드시 운영 URL에서 재확인하세요.
