일부러 안 바꾼 것

  • 이용권 코드의 'KIG-' 머리 — 이미 나간 코드가 그대로 쓰여야 해서 그대로 둡니다. 이용권 창의 입력 예시('KIG-1Y-XXXX…')도 실제 코드 모양이라 그대로입니다.
  • 사이트 주소 k-ig-core.vercel.app — 주소(도메인)를 바꾸는 일은 사장님 몫입니다.
  • 옛 교재 원문 속 'K-IG 교육' — 강의 자료 안에 남아 있지만 화면에는 나오지 않습니다(찍은 36쪽에서 옛 이름 0곳).
  • 학습자 기기에 저장된 진도 · 북마크 이름표 — 바꾸면 저장된 진도가 사라져서 그대로 둡니다.
