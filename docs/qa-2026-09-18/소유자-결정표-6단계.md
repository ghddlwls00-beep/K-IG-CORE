## 가. 채점 — 학습자 점수에 바로 닿는 것

**1. 듣기 받아쓰기: 소리대로 쓴 숫자·하이픈도 정답으로** (17건, G1)
- 문제: 소리로는 "two o'clock" 인데 정답이 "2:00" 이라 들리는 대로 쓰면 틀림. "left-handed" 를 띄어 써도 틀림(하이픈은 소리로 안 들림).
- 추천: 들리는 대로 쓴 것도 정답(숫자·낱말, 하이픈 붙임·띄움 모두). **다른 숫자는 여전히 틀림.** 채점 코드 한 곳, 음성·문장 그대로.
- 다른 길: 그대로 둠(힌트 칸의 숫자를 보고 쓰라는 뜻).

**2. 문법: 짧은 문장에서 단어 하나 더 쓰면 0점 → 70점으로** (G11)
- 문제: 6낱말 이하 문장(전체의 65%)에서 the · a 같은 작은 단어 하나만 더 써도 0점. 긴 문장에서는 같은 실수가 70점.
- 추천: 더 쓴 것이 작은 단어 하나뿐이면 70점. 만점은 하나도 안 늘어남. 채점 코드 한 곳.
- 다른 길: 그대로(문항마다 다른 정답을 하나씩 추가).

**3. 문법: '그것' 을 that 으로 써도 정답?** (G9)
- 추천: '그것' 문항 80개를 하나씩 보고 that 이 같은 뜻인 곳만 정답으로 추가. '그 책' 같은 '그 N' 280곳은 지금처럼 70점(둘 다 만점으로 하면 거의 모든 문항에 '다른 정답' 이 붙음).
- 다른 길: 지금대로 / '그 N' 도 모두 만점.

**4. 문법: 한국어에 표시가 없는 시제** (G10)
- 진행형 — 추천: 두 뜻이 다 자연스러운 12문항만 "~하고 있다" 영어도 정답으로.
- 현재완료 — 추천: 그대로(후보 44개 대부분이 바꾸면 틀리거나 뜻이 바뀜).

**5. 문법: "All … not" 부분 부정** (6-1393, 5문항)
- 문제: "모두가 ~하지는 않는다" 를 가르치는 과인데, 원어민에게는 뜻이 둘로 읽히는 "All of them don't …" 가 만점 정답으로 화면에 보임.
- 추천: 그 5개를 '다른 정답' 에서 빼고 분명한 "Not all …" 만 만점(뺀 꼴로 쓰면 70점).
- 다른 길: 그대로(너그럽게).

## 나. 옛 글 · 차별적 내용

**6. 듣기: 1960~70년대 시점이 그대로인 글** (7건, G3)
- 예: "지금 컬러 방송이 시작됐다", "이 파도 풀장에서 지금도 서핑한다"(2020년 폐장).
- 추천: 영어·음성은 그대로, 한국어 해석 첫 줄에 "※ 이 글은 1960~70년대에 쓰였습니다" 안내.
- 다른 길: 틀린 문장만 과거형으로(음성 새로) / 그대로.

**7. 듣기: 강 전체가 옛 차별적 시선인 글** (2건, G4)
- 서커스 구경거리 글(장애·체형 비하 표현), 인종차별 영화 『국가의 탄생』 을 설명 없이 칭찬하는 글.
- 추천: 영어는 그대로, 한국어 첫 줄에 "※ … 지금은 쓰지 않는 차별적 표현(작품)입니다" 안내.
- 다른 길: 글을 새로 씀 / 강의를 뺌(회차 번호가 바뀜) / 그대로.

**8. 9/17 에 "둘지" 정하시던 듣기 강의 3개** (4건, G5)
- 추천: 세 강 모두 두고 고침 — d215 원주민 머리가죽 예시 → 고대 이집트 부적 예시 · d234 민스트럴 쇼 글은 두 곳 고치고 한국어 첫 줄에 "※ 민스트럴 쇼는 백인이 얼굴을 검게 칠하고 흑인을 조롱한 공연으로, 지금은 대표적인 인종차별로 여겨집니다"(이 문구도 확인해 주세요) · d257 "원시 인디언 주술사" 두 문장을 d256 과 같은 방식으로. 음성 7개.
- 다른 길: 그대로 두고 안내만 / 강의를 뺌.

**9. 듣기: 사람 일반을 'he', 'man' 으로 부르는 옛 문체** (2건, G2)
- 추천: 명백히 틀린 단정만 고치고 문체는 그대로(이미 고친 곳 있음).
- 다른 길: they/people 로 모두 다시 씀(강의마다 여러 문장, 음성 새로).

**10. 듣기 d050: "아내는 집에서 아이를 봐야 한다" 로 끝나는 예시** (6-0041)
- 추천: 부부가 함께 자선 행사에 나가는 이야기로 네 문장 고침. 교훈 그대로, 음성 4개.
- 다른 길: 그대로.

**11. 읽기 pr167: "아이는 집중 교육으로만 모국어를 배운다" 는 옛 주장** (6-1199)
- 추천: 영어는 그대로, 한국어 해석 끝에 "※ 옛 관점의 글이며, 현대 언어학에서는 아이들이 들으며 스스로 익힌다고 봅니다".
- 다른 길: 지문을 다시 씀(단어 카드 4장·빈칸 문제도 바뀜).

**12. 읽기: 날짜 없는 옛 내용** (2건, G7)
- pr182 오렌지 주스("최근에야 캔으로" — 실제로는 80년 전) — 추천: "1900년대 초에는 …, 그 뒤 캔으로 …" 로 다시 씀, 빠지는 단어 카드 3장은 새 단어로.
- pr024 외국인 유학생 "1년도 안 돼 6배" (출처 없음, 통계와 안 맞음) — 추천: 숫자를 빼고 "특히 서울에서 크게 늘었다".
- 다른 길: 한국어 안내만 / 그대로.

**13. 문법: 2002년 뉴스로 만든 문장이 지금 일처럼** (8페이지, 6-1516)
- 예: "파월 국무장관이 귀국하고 있다", "무바라크 대통령".
- 추천: 그 8페이지 부제목에 "2002년 뉴스 방송 기반 문장입니다" 한 줄. 영어·음성·채점 그대로.
- 다른 길: 그대로 / 문장을 과거형으로(음성 새로).

**14. 문법: 옛 의학 용어 "sex change operation"** (6-1512)

- 다른 길: 한국어도 바꿈 / 그대로 / 다른 문장으로 교체.

## 다. 초등(STUDENT) 한국어 해석

**15. 선생님을 '그/그녀/그들' 로 부름** (23문단, G14)
- 가족 어른(어머니·아버지 등)은 이미 '그분' 으로 고침. 선생님만 남음.
- 추천: 선생님도 '그분 · 그분들' 로. 한국어 음성 23개.
- 다른 길: 그대로(높임 동사만 맞춘 지금 상태).

**16. '나' 와 '저' 가 한 강의 안에서 섞임** (10강의, G13)
- 추천: 강의 안에서만 많은 쪽으로 맞춤(문단 약 20, 음성 같은 수).
- 다른 길: 과정 전체를 '저' 로(문단 213) / 그대로.

**17. 띄어쓰기: '저녁식사', '영어학원' 처럼 붙여 쓴 말** (19곳, G15)
- 추천: 표준 띄어쓰기로(문단 약 17, 한국어 음성 같은 수 — 소리는 같음).
- 다른 길: 그대로(이 과정의 표기 습관으로 둠).

## 라. 구성 · 중복

**18. 단어 과정: 같은 단어가 여러 강의에 되풀이** (G6 + 7단계 "같은 단어 반복 95건")
- 예: 2단계 강의 11~20 단어의 54% 가 1단계에도 나옴.
- 추천: 그대로(앞 단계 복습으로 봄. 틀린 카드는 없음). 이 답 하나로 7단계의 같은 질문도 닫힙니다.
- 다른 길: 한 과정 안의 되풀이만 새 단어로 바꿈 / 과정 소개에 "앞 단계 복습 포함" 한 줄.

**19. 문법: 같은 문항이 한 세트에 두 번** (7건, G8)
- 추천: 두 번째 것을 새 문항으로(교재 원본이 없어 새로 지음, 음성 10개). 단 과 경계의 복습으로 보이는 2건(gh1-092 #39, 분할 페이지 #90)과 존댓말만 다른 1건은 그대로.
- 다른 길: 모두 그대로(복습으로 둠).

**20. 문법 I: 단계 이름이 내용과 안 맞음** (6-1372)
- 3단계 이름이 "조동사 & 수동태" 인데 실제로는 조동사·수동태 문항이 0개.
- 추천: 3단계만 내용대로 "진행형 · 부가의문문 & 기초 문형 복습" 으로.
- 다른 길: 여섯 단계 이름을 모두 새로 지음(사장님이 이름을 고름) / 그대로.

**21. 읽기 pr213: 한 지문에 두 이야기가 표시 없이 붙어 있음** (6-1239)
- 추천: 한국어 해석에만 "(이야기 1)", "(이야기 2)". 영어 문장은 말하기 채점에 쓰여 그대로.
- 다른 길: 영어에도 표시 / 잇는 문장 하나 추가 / 그대로.

**22. 초등 '청크 드릴' 데이터의 오류** (44건, G12) — **지금 정하실 것 없음**
- 드릴은 화면에 안 나오는 데이터이고, 사장님이 이미 "지금 정하지 않는다, 데이터 그대로" 로 정하셨습니다(BUG-024).
- 나중에 드릴을 되살리기로 하시면 이 44건을 먼저 고칩니다.
