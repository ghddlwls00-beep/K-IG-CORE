# 이용권 공백 기록 정리 — 확인 절차 (소유자용 한 장)

> 7단계 7-4 e · 2026-09-24 · 수정 세션이 썼습니다. **이 절차의 값(열쇠)은 AI 에게 주지 마세요** — 이 채팅에도, 파일에도 붙여넣지 않습니다.

## 무엇을 하는 것인가

예전에는 이용권 코드 가운데에 공백을 넣으면(`KIG-1Y-AAAA BBBB-CCCC`) 따로 된 이용권처럼 저장됐습니다(BUG-002).
사이트는 2026-09-22 에 고쳐서 지금은 맞게 동작합니다. 다만 그때 이미 공백 섞인 이름으로 저장된 **옛 기록**이 운영 저장소에 남아 있을 수 있습니다.
남아 있으면, 관리자가 그 이용권의 "기기 초기화" 를 누를 때 옛 기기가 되살아날 수 있습니다.
이 절차는 **옛 기록이 있는지 확인만** 하고(아무것도 안 바꿈), 있을 때만 백업 → 정리합니다.

이 컴퓨터의 `.env.local` 에는 운영 이용권 저장소 열쇠 두 개(`R2_LICENSE_BUCKET` · `LICENSE_STORAGE_SECRET`)가 없어서, AI 는 돌릴 수 없습니다.

## 준비 (1분)

1. Vercel → 이 프로젝트 → Settings → Environment Variables → **Production** 에서 두 값을 봅니다:
   `R2_LICENSE_BUCKET` · `LICENSE_STORAGE_SECRET`. (아직 복사하지 않아도 됩니다 — 아래 3번에서 하나씩 붙여넣습니다.)
2. **새** PowerShell 창을 열고 저장소 폴더로 갑니다:
   ```powershell
   cd C:\Users\ghddl\.gemini\antigravity\scratch\K-IG-CORE
   ```
3. 아래 두 줄을 **한 줄씩** 붙여넣고, 각 줄 다음에 나오는 입력 칸에 Vercel 의 값을 붙여넣고 Enter.
   (값을 명령줄에 직접 쓰면 PowerShell 이 명령 기록 파일에 남기므로, 입력 칸으로 받습니다. 입력 칸은 기록에 남지 않습니다.)
   ```powershell
   $env:R2_LICENSE_BUCKET = Read-Host "R2_LICENSE_BUCKET 값"
   $env:LICENSE_STORAGE_SECRET = [Runtime.InteropServices.Marshal]::PtrToStringAuto([Runtime.InteropServices.Marshal]::SecureStringToBSTR((Read-Host "LICENSE_STORAGE_SECRET 값" -AsSecureString)))
   ```
4. R2 접속 열쇠 세 개(`R2_ACCOUNT_ID` · `R2_ACCESS_KEY_ID` · `R2_SECRET_ACCESS_KEY`)는 `.env.local` 에 있습니다.
   백업 도구는 `.env.local` 을 스스로 읽지 않으므로, 이 창에만 옮겨 둡니다(화면에 찍지 않음):
   ```powershell
   Get-Content .env.local | ForEach-Object { if ($_ -match '^\s*(R2_ACCOUNT_ID|R2_ACCESS_KEY_ID|R2_SECRET_ACCESS_KEY)\s*=\s*(.*)$') { Set-Item "env:$($matches[1])" $matches[2].Trim().Trim('"',"'") } }
   ```

## 확인 (아무것도 바꾸지 않음)

```powershell
node scripts/migrate-license-key-whitespace.mjs
```

- **첫 줄을 먼저 보세요.** `저장소 : R2 (운영 기록)` 이어야 합니다.
  `로컬 파일 (data/license-devices.json)` 이라고 나오면 열쇠 하나가 빠진 것입니다 — 그 결과는 운영이 아니니 믿지 말고 3~4번을 다시 하세요.
- 둘째 줄이 `모드 : 확인만 (아무것도 바꾸지 않음)` 인지 봅니다.
- `정리 대상 : 0개` → **끝입니다.** 아래 "마치기" 로.
- `정리 대상 : N개` (0 이 아님) → 이용권 코드는 가려진 채(앞뒤 몇 글자만) 기기 수 · 환불 차단이 합치면 어떻게 되는지 나옵니다. 아래로.

## 0 이 아닐 때만 — 백업 → 정리

1. 백업(읽기만 — 저장소 밖으로 복사):
   ```powershell
   node scripts/backup-license-data.mjs --out D:\kig-backup
   node scripts/backup-license-data.mjs --out D:\kig-backup --verify
   ```
   D 드라이브가 없으면 저장소 **밖**의 다른 폴더(예: `C:\kig-backup`). 저장소 안에 두지 마세요 — 고객 기록이 커밋될 수 있습니다.
2. 정리(쓰기 · 옛 기록 삭제):
   ```powershell
   node scripts/migrate-license-key-whitespace.mjs --apply
   ```
3. 다시 확인 — `정리 대상 : 0개` 가 나와야 합니다:
   ```powershell
   node scripts/migrate-license-key-whitespace.mjs
   ```
4. 결과 목록에 `⚠`(합친 뒤 기기 수가 한도를 넘음)가 있었다면, 그 이용권은 `/admin/license` 에서 확인해 필요하면 "기기 초기화".

## 마치기

- 이 PowerShell 창을 **닫습니다** — 넣은 값은 창과 함께 사라집니다(파일에 쓰지 않았음).
- 복사해 둔 값이 클립보드에 남아 있을 수 있으니, 다른 글자를 한 번 복사해 덮어 두세요.
- 수정 세션에는 **숫자만** 알려 주세요: "정리 대상 N개 · (정리했으면) 다시 확인 0개". 코드 · 값은 알려 주지 않습니다.
