7-1. 점검 도구 수리 — 최종 재점검 전에 반드시
────────────────────────────────────────────────────

세 가지 모두, 고친 뒤 "그 검사가 실패를 잡는지" 를 먼저 증명해라. 일부러 틀린 입력을 넣어
고치기 전 도구로는 못 잡고, 고친 도구로는 잡는 것을 보여라. 항상 통과하는 검사는 검사가 아니다.

a. 서버 오류 기록이 지워지는 문제
   docs/qa-2026-09-18/scripts/lib/harness.cjs:224 의 tab.resetEvents() 가 동작마다 네트워크
   기록을 지운다. 그래서 9/18 기록 5,530건 중 3,071건에 요청 기록이 하나도 없고, 보고서는
   "서버 오류 판정 불가" 라고 적었다. 지우기 전에 누적해 두었다가 기록에 남기게 고쳐라.
   증명: 로컬에서 페이지가 없는 주소를 하나 요청하게 만들어(예: 브라우저에서 fetch) 그 404 가
   기록에 잡히는지. 고치기 전 도구로는 사라지고, 고친 도구로는 남아야 한다.

b. STUDENT 받아쓰기 241강 — BLOCKED
   드라이버가 같은 낱말이 두 번 나오는 문장을 조립하지 못한다(9/18 보고서 B절·J절, 세 가지
   방법 시도·실패). 타일을 글자가 아니라 화면의 자리(순번)로 골라 누르게 고쳐라.
   소유자가 /student/s1-4 에서 손으로 조립해 "정답" 이 뜨는 것을 확인한 경우가 기준이다.
   증명: 같은 낱말이 두 번 든 문장이 있는 강의에서, 고치기 전 드라이버는 조립 실패, 고친
   드라이버는 "정답". 그다음 241강 전부를 다시 돌려 BLOCKED 를 0 으로 — 남으면 강의마다 사유.

c. 새 검사 — 강의 파일에 있는데 학습자 화면에 한 번도 닿지 않는 데이터
   BUG-024(STUDENT 청크 드릴 1,050개)와 LISTENING 죽은 사본(2,518블록)이 이 종류다. 하나는
   감사가 잡았고 하나는 놓쳤다. 사람 눈이 아니라 규칙으로 잡아라.
   원리: 과정마다 화면 코드(각 LearningView 와 LessonBody 분기)가 실제로 읽는 필드·블록 종류를

   주소가 있는 6개 과정만 본다(validRoutes.json). CNN·GVA·basics·middle 은 대상 아님.
   증명: 이미 아는 것이 목록에 나와야 한다 — STUDENT chunkDrills, BUG-013 에서 뺀 대본 안내문의
   옛 판(커밋 8325e10 의 dNNN-1.json). 안 나오면 검사가 틀린 것이다.
   새로 나온 것은 등록부에 새 BUG 로 올리고, 고칠지는 소유자 결정 대기로.

7-2. 음성 생성기 비용 함정
────────────────────────────────────────────────────

scripts/generate-azure-ava.mjs 는 .env.local 을 읽지 않는다. R2 자격이 없으면 경고만 하고
(195~210행) 이 컴퓨터의 파일만 기준으로 계속 간다. public/audio 는 git 에 없으므로 새로 받은
저장소에서는 모든 클립이 없는 것으로 보이고, 주석 표현대로 "한 달 문자 한도를 몇 배" 쓴다.

고칠 것:
  - upload-azure-ava-r2.mjs 의 loadEnvLocal() 과 같은 방식으로 .env.local 을 읽어라.
    실제 환경변수가 이긴다. 값은 절대 출력하지 마라.
  - R2 목록을 못 보면 생성 단계로 넘어가지 말고 멈춰라(exit 1). --dry-run 은 계속 허용하되
    "R2 를 못 봐서 이 숫자는 이 컴퓨터 기준" 이라고 첫 줄에 크게 찍어라. 이 컴퓨터 기준으로
    생성하려면 이름이 분명한 플래그(예: --allow-local-only)를 따로 줘야만 하게 해라.
증명: 자격을 지운 셸에서 생성 명령 → Azure 를 한 번도 부르지 않고 멈춤(exit 1). 자격이 있으면
  --dry-run 의 pending 이 고치기 전과 같음. Azure 호출은 하지 마라 — 멈춤과 dry-run 으로만 증명.
그다음 AGENTS.md 의 "--env-file" 임시 안내를 원래 명령으로 되돌려라.

   유출 검사 0 유지, 새 경로도 유출 검사에 넣어라. 무료 이용자에게 무엇이 보이는지 보고해라.

b. BUG-018 이용권 코드 저장 (findings-log PRIV-01)
   소유자 결정: 추천안 A — 토큰 형식을 바꿔 서버가 코드 없이 토큰만으로 검증 — 을 **다른 변경과
   섞지 않은 별도 커밋**으로 준비한다. 배포도 그 커밋만 따로 한다.
   반드시 들어가야 할 것:
     - 이미 코드가 저장된 기존 사용자가 바뀐 뒤에도 끊기지 않고 새 형식으로 넘어가는 경로
     - 서버 verify · deactivate · 세션 복원, "내 이용권" 창, 진도 옮기기 표시가 코드 없이 동작
     - 되돌리는 방법 (그 커밋 하나를 되돌리면 되는지)
   너는 이용권 코드를 쓸 수 없으므로, 소유자가 실제 코드로 시험할 **한 장짜리 시험지**를 만들어라:
     새 기기 등록 · 두 번째 기기 · 세 번째 기기 거부(2대 제한) · 해제 · 환불 차단된 코드 거부 ·
     관리자 초기화 · "내 이용권" 표시 · 진도 옮기기 · 기존 사용자 전환.
   이 시험지는 9/18 보고서 H절 "확인 못 한 것 ① 이용권 발급·차단·초기화의 실제 동작" 도 덮는다.
   소유자 시험을 통과하기 전에는 운영에 내보내지 않는다.

c. BUG-024 STUDENT 청크 드릴 — 소유자 결정 대기
   2026-09-07 83b007c "remove chunk reading tab" 으로 명시적으로 뺀 기능이다. 소유자 답이 올 때까지

   데이터 지우기(LISTENING 죽은 사본과 같은 방식) / 두기 중 하나를 그대로.

d. VOCA-REPEAT-01 — 같은 낱말이 서로 다른 강의 4~5곳에 반복 95건
   나선형 복습 설계인지 소유자에게 한 줄로 물어라. 설계면 "관찰 — 설계대로" 로 종결.
