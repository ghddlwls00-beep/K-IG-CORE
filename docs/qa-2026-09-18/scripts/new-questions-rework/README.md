# 새 문제 오답 보기 다시 쓰기 — 클라우드 세션 작업 지시서 (2026-10-01)

## 왜
- 사이트에 올라간 새 문제 1,268개(content/questions — LISTENING 276강 756 · READING 256강 512)는 정답과 근거가 맞지만,
  **강의를 듣지도 읽지도 않은 AI 가 칩 · 물음 · 보기만 보고 LISTENING 81% · READING 87% 를 맞혔다**(그냥 찍으면 25%) — 2026-09-29 '듣지 않고 맞혀 보기'.
  오답 보기가 글을 몰라도 지워진다: 상식에 어긋남 · '만 · 모든 · 전혀' 같은 극단적인 말이 오답에만(295문항) · 칩 말이 정답 쪽만 가리킴 · 오답이 물음과 어긋남 · 오답 둘이 같은 쪽이라 함께 떨어짐 · 정답만 '가장 그럴듯하고 균형 잡힌 말'.
- 사장님 결정: 이 다시 쓰기를 클라우드 크레딧으로 지금 한다.

## 목표(이것을 재서 통과해야 끝)
1. '듣지 않고 맞혀 보기'(아래 4) 맞힌 비율 **LISTENING ≤ 40% · READING ≤ 40%**.
2. 극단적인 말이 오답에만 있는 문항 ≤ 10%(`blind-score.cjs` 가 셈). 극단적인 말은 정답 · 오답 어디에든 비슷하게, 아니면 쓰지 않기.
3. `node docs/qa-2026-09-18/scripts/check-new-questions.cjs --dir content/questions` PASS(길이 순위 · 자리 · 튀는 보기 · 겹침 요령 · 칩 숫자 · 모양 · 근거 줄).
4. 정답의 뜻 · 근거 줄 · id · type · 문항 수는 그대로. 정답 문구는 '가장 그럴듯한 말'로 튀지 않게 다듬어도 됨(뜻은 같게).

## 손대면 안 되는 것
- content/lessons/** · content/ld_english_scripts.json · 소리 · src/ 코드 · 다른 과정. **고치는 것은 content/questions/{ld,reading}/*.json 뿐**,
  그리고 같은 내용을 docs/qa-2026-09-18/학습법-화면-0927/새-문제/{ld,reading}/ 에 그대로 복사(두 곳이 늘 같아야 함).
- main 에 직접 올리지 말 것. 브랜치 `claude/question-rework` 에 커밋 · 푸시. 운영 올리기는 사장님 컴퓨터의 세션들이 함.

## 좋은 오답 보기(쓰는 법)
- 글을 모르는 사람에게는 **정답만큼 그럴듯해야** 한다: 같은 화제 · 상식에 맞음 · 물음과 맞물림 · 길이 · 말투가 정답과 비슷. 그러나 **글로는 분명히 틀린** 것(글과 반대 · 다른 사람 · 다른 숫자 · 다른 때 · 글에 없는 일).
- 네 보기가 서로 다른 '그럴듯한 답'이 되게: 둘이 한 편이라 같이 떨어지지 않게, 한 보기만 균형 잡히고 나머지는 극단적이지 않게.
- LISTENING: 칩(1단계에서 듣기 전에 보임 — `lib.cjs chipsOf`)의 말 · 숫자가 정답 쪽만 가리키지 않게. 칩 말을 쓰면 오답에도 고르게.
- 자연스러운 한국어(중고생) · 물음 끝 '…것은?/…무엇인가?' · 보기 끝 마침표 없음 · 숫자는 아라비아 숫자 · 이름은 한글 표기, 강의 안에서 같게.
- 같은 강의의 다른 문항 답을 흘리지 않게. 물음에 줄 번호를 쓰지 않음.

## 순서
1. `node docs/qa-2026-09-18/scripts/new-questions-rework/blind-score.cjs` 를 쓰려면 먼저 기준 측정: 
   `node .../blind-packets.cjs --out /tmp/blind --key /tmp/blind-key.json` → 아래 4의 맞혀 보기 워크플로우 → `blind-score.cjs <결과> /tmp/blind-key.json --out /tmp/guessable.json`.
   (09-29 값: LD 81% · RD 87% — 다시 재서 시작점을 남김.)
2. 다시 쓰기 워크플로우(workflow-authoring 스킬 참고 · `wf-chunk-reference.js` 의 규칙 글 · 칩 다루기 · 레인 방식을 본뜸 — 그 파일의 C:/ 경로는 옛 로컬 경로라 저장소 기준으로 바꿔 쓸 것):
   강의 묶음(LISTENING 7강 · READING 8강)마다 일꾼 하나(지금 모델 · 대본/지문 전체와 칩을 읽고 그 묶음의 **모든 문항**을 위 '좋은 오답 보기'대로 다시 씀 → 정답 · 오답을 글에 다시 맞춤 →
   묶음 파일만 모은 임시 폴더({ld|reading}/)에 `check-new-questions.cjs --dir <임시> --detail` PASS → content/questions 와 docs 사본에 씀).
   일꾼에게: 이 일 하나만 · 사용량 · 다른 세션 보지 말 것 · 계획 문서 읽지 말 것 · 빈 결과 금지.
3. 전체 `check-new-questions.cjs --dir content/questions` PASS · 두 폴더 같음 확인 → 커밋 · `claude/question-rework` 푸시(중간에도 묶음 절반마다 커밋 · 푸시 — 일이 끊겨도 남게).
4. **맞혀 보기 다시**: 새 packets → Sonnet(effort low) 일꾼이 묶음 파일 하나만 읽고 칩 · 물음 · 보기만으로 고름(`wf-blind-guess-reference.js` 그대로 — 다른 파일 열지 말 것). 
   목표 1 · 2 를 못 넘은 문항만 다시 2단계(최대 2바퀴).
5. 끝에 `docs/qa-2026-09-18/학습법-화면-0927/새-문제/다시-쓰기-결과.md`: 전 · 후 맞힌 비율(과정별) · 극단적인 말 수 · 바꾼 문항 수 · 검사 PASS 줄 · 깨기(`--break rank|chips|converge`) FAIL 확인 · 같은 AI 계열이 쓰고 점검했다는 한 줄. 커밋 · 푸시.
