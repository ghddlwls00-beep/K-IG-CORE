# 이용권 시험지 — BUG-018 (코드를 브라우저에 두지 않기) · 소유자용 한 장

> 7단계 7-4 b · 2026-09-24 · 수정 세션이 썼습니다. AI 는 이용권 코드를 쓸 수 없어 **실제 코드로 누르는 시험은 소유자님만** 할 수 있습니다.
> 이 시험을 통과하기 전에는 운영에 내보내지 않습니다(소유자 결정 2026-09-23). 9/18 보고서 H절 "확인 못 한 것 ① 이용권 발급 · 차단 · 초기화의 실제 동작" 도 이것으로 덮습니다.

## 무엇이 바뀌나 (쉬운 말)

- 전에는 이용권을 등록하면 **코드 원문이 브라우저 저장소에 그대로** 남았고, 로그인 쿠키 안에도 풀면 읽히는 모양으로 들어 있었습니다.
- 이제 브라우저에는 **서버가 서명한 표(토큰)** 만 남고, 그 안의 코드는 서버만 풀 수 있게 잠겨 있습니다. "내 이용권" 창에는 코드가 **가려서** 보입니다(예: `KIG-1Y-A1B2…C3D4`).
- 이미 등록해 둔 학습자는 사이트를 한 번 열 때 자동으로 새 표로 바뀝니다 — 코드를 다시 넣지 않습니다.

## 준비

- **시험용 코드**를 쓰세요 — `/admin/license` 에서 새로 발급한 것(고객 코드 말고). 1년권 하나, 가능하면 STUDENT 권 하나.
- 이 변경만 담은 판을 **미리보기 주소**(Vercel Preview)로 띄워 그 주소에서 시험합니다. 운영 이용권 저장소를 쓰는 미리보기여야 실제 동작과 같습니다.
  - **누가 띄우나**: 이 변경만 담은 가지를 만들어 올리는 일(가지 푸시)은 소유자 몫입니다 — 허락해 주시면 수정 세션이 가지를 만들어 드립니다(소유자 혼자서는 이 파일들만 골라 가지를 만들기 어렵습니다).
  - **먼저 확인 한 줄**: Vercel → Settings → Environment Variables 에서 `LICENSE_SECRET` · `LICENSE_SALT` · `R2_LICENSE_BUCKET` · `LICENSE_STORAGE_SECRET` · `R2_ACCOUNT_ID` · `R2_ACCESS_KEY_ID` ·
    `R2_SECRET_ACCESS_KEY` 가 **Preview 칸에도 ✔** 인지 봅니다. 하나라도 빠지면 미리보기가 조용히 서버 안의 임시 파일 저장소로 돌아, 아래 결과가 운영과 달라집니다(공백 기록 절차서의 '첫 줄이 R2 인지' 와 같은 함정).
- 기기: PC 1대(크롬) + 휴대폰 1대 + 세 번째로 쓸 브라우저(다른 PC 크롬 · 휴대폰의 다른 브라우저 등).

## 시험 (한 줄씩 — 되면 ✔)

| # | 할 일 | 되어야 하는 것 |
|---|---|---|
| 1 | **새 기기 등록** — PC 에서 시험 코드 등록 | "등록되었습니다 (기기 등록 현황 1/2대)" · 유료 강의가 열림 |
| 2 | **"내 이용권" 표시** — 오른쪽 위 이용권 단추 → 창 | 플랜 · 기간이 맞음 · 코드는 `KIG-1Y-XXXX…YYYY` 처럼 **가려서** 보임(전체가 보이면 ✘) |
| 3 | (PC 만) **코드가 브라우저에 없나** — 크롬 F12 → Application → Local Storage → 사이트 주소 → `kig:license:v1` | 값에 `"key"` 칸이 **없음** · `maskedKey` · `token` 만 |
| 4 | **두 번째 기기** — 휴대폰에서 같은 코드 등록 | "기기 등록 현황 2/2대" · 유료 강의가 열림 |
| 5 | **세 번째 기기 거부** — 세 번째 브라우저에서 같은 코드 등록 | "최대 기기 수(2대)를 초과" 안내 · 열리지 않음 |
| 6 | **해제** — 휴대폰의 "내 이용권" 창에서 이 기기 해제 | 휴대폰 강의가 잠김 · 세 번째 브라우저에서 다시 등록하면 이제 **됨**(2/2) |
| 7 | **진도 옮기기** — STUDENT 권으로 PC 에서 STUDENT 한 강을 끝낸 뒤, 다른 기기에서 같은 코드로 | 끝낸 강 · 열린 챕터가 **두 기기에서 같음** |
| 8 | **관리자 초기화** — `/admin/license` 에서 시험 코드의 "기기 초기화" | 등록했던 기기들이 모두 잠김 · 다시 등록하면 됨 |
| 9 | **환불 차단된 코드 거부** — `/admin/license` 에서 시험 코드 "차단(환불)" → 등록된 기기 새로고침 · 새 기기 등록 | 둘 다 거부("환불 처리되어 사용이 영구 중지") · 시험 뒤 "차단 해제" |
| 10 | **기존 사용자 전환** — 이 변경을 올리기 **전** 운영에서 등록해 둔 기기(PC 크롬 권장)로, 변경을 올린 **뒤** 사이트를 엶 | 코드를 다시 넣지 않아도 그대로 로그인 · "내 이용권" 에 가린 코드 · (PC) `kig:license:v1` 에 `"key"` 칸이 **사라짐** |

10번은 운영에 올린 뒤에만 볼 수 있습니다 — 미리보기에서 1~9 가 모두 ✔ 이면 올리고, 올린 직후 10번을 보세요.

## 되돌리는 방법 · 되돌리면 생기는 일

- 이 변경은 **커밋 하나**입니다(다른 7단계 변경과 섞지 않음). 되돌리려면 그 커밋 하나를 되돌려 다시 배포하면 됩니다.
- 되돌리면: 이미 새 표로 바뀐 학습자의 브라우저에는 코드가 없으므로, 옛 판은 그 기록을 "믿을 수 없음" 으로 지웁니다 → 그 학습자들은 **코드를 한 번 다시 입력**해야 합니다(기기 자리 · 진도는 서버에 그대로라 잃는 것은 없음).
  그래서 되돌리기는 1~10 에서 이용권이 **아예 안 되는** 문제가 났을 때만 권합니다.

## 알려 주실 것

숫자만: "1~9 중 ✔ N개 · ✘ 번호" (올린 뒤 10번 ✔/✘). 코드 · 화면의 가린 코드 · 토큰 값은 알려 주지 않습니다.
