====================== 여기서부터 복사 ======================

최종 출시 관문이다. 고치지 마라. 확인만 해라. 문제를 찾으면 보고하고 멈춰라.

운영(https://k-ig-core.vercel.app)에서 확인한다. 로컬 결과는 근거가 되지 않는다.

■ 지킬 것
  이미 등록된 감사용 프로필을 써라. 새 기기를 등록하지 마라.
  이용권 코드·비밀번호·관리자 PIN 을 타이핑하지 마라.
  /api/license/ 중 상태를 바꾸는 것과 /api/admin/ 의 변경 계열을 부르지 마라.
  CNN · GVA 는 폐지 과정이다. 건드리지 마라.
  법률 문서·결제 연결·저작권 검토는 소유자가 직접 한다. 확인 대상이 아니다.

■ 관문 1 — 이용권 없이 열리는 유료 주소가 0건인가
  로그아웃 상태로 유료 주소 1,595개 전부를 확인해라. 표본이 아니다.
  숫자로: 잠긴 것 N / 열린 것 N.  열린 것이 1개라도 있으면 출시 불가다.

■ 관문 2 — 무료 체험 28개가 여전히 열리는가
  숫자로: 열린 것 N / 28.  28 미만이면 출시 불가다.
  돈 낸 사람이 아니라 체험하러 온 사람이 막히는 것이라 매출이 그대로 사라진다.

■ 관문 3 — 공개 자바스크립트에 유료 본문이 새는가
  배포된 번들 전체를 받아 유료 강의 본문 문자열이 들어 있는지 검사해라.
  숫자로: 검사한 파일 N개 / 유출 N건.  0이 아니면 출시 불가다.

■ 관문 4 — 정답인데 오답 처리되는 채점이 0건인가
  GRAMMAR 종합 평가 282강과 STUDENT 받아쓰기 2,217문장을 전부 돌려라.
  숫자로: 검사 N건 / 정답인데 오답 처리된 것 N건.  0이 아니면 출시 불가다.

■ 관문 5 — 음성이 끊기는 곳이 없는가
  모든 과정의 음성 버튼을 눌러 재생 실패 수를 세라.
  숫자로: 누른 횟수 N / 재생 실패 N.  실패가 있으면 어느 강의인지 전부 적어라.

■ 관문 6 — 커버리지에 NOT TESTED 가 0인가
  build-coverage.cjs 로 PASS/FAIL/BLOCKED/NOT TESTED 를 다시 집계해라.
  NOT TESTED 가 0이 아니면 출시 불가다.
  BLOCKED 가 있으면 각각 왜 막혔는지 사유를 적어라. 사유 없는 BLOCKED 는 미점검이다.

■ 관문 7 — 심각한 사실 오류 3건이 실제로 고쳐졌는가
  content-fix-list.md 의 [Critical] 3건을 운영 화면에서 하나씩 열어 확인해라.
  고쳐진 내용이 화면에 나오는지, 그 문장의 음성이 새 내용으로 들리는지.

■ 관문 8 — 구매 주소가 설정됐는가
  배포된 페이지에서 "구매 링크 준비 중" 문구가 나오는지 확인해라.
  ※ 설정은 소유자가 한다. 너는 상태만 보고해라. 결제 화면에 들어가지 마라.

■ 보고 형식
  관문마다 한 줄로: "관문 N — 통과 / 불통과, 근거 숫자".
  불통과가 하나라도 있으면 제일 위에 쓰고, 나머지도 끝까지 다 확인해라.
  하나 막혔다고 중간에 그만두지 마라. 사장이 전체 그림을 봐야 한다.

  마지막에 이 문장을 그대로 적어라:
  "이 점검은 수정을 한 세션이 직접 수행했습니다. 독립적인 검토가 아닙니다."

## 결과를 받으면

관문 1~7 이 전부 통과해도 **자동으로 GO 가 되지는 않습니다.** 소유자가 처리하기로 한
세 가지(법정 표시·구매 주소·저작권 검토)가 남아 있고, 그것까지 끝나야 GO 입니다.

그리고 아직 아무도 확인하지 않은 것이 하나 있습니다 — **실제 아이폰·안드로이드 기기**입니다.
자동 점검은 전부 컴퓨터의 브라우저로 했습니다. 출시 전에 실제 휴대폰으로 30분만
직접 만져 보시는 것을 권합니다. 특히 음성 재생과 받아쓰기 입력입니다.
