# 디자인 규칙 — 모든 과정 · 새 과정(PASS-OFF GRAMMAR 포함) 공통

> v1 · 2026-09-27. 사장님: "디자인 규칙과 공통 틀같은 것들은 옆 세션에도 똑같이 적용되게" · "옆세션이 만들고 있는것도 유아이 유엑스가 여기서 만들어질거랑 통일되게 해".
> 근거: 학습법 · 화면 전수 점검(`docs/qa-2026-09-18/학습법-화면-0927/`) — 사장님이 휴대폰은 "겁나 불편", 데스크탑은 "어지럽고 조잡" 하다고 하신 까닭을 사진 · 숫자 · 코드 줄로 짚은 것.
> 화면을 새로 만들거나 고치는 세션은 이 문서를 먼저 읽고 지킵니다. 규칙을 바꿀 때는 이 파일을 고치고 버전을 올립니다.

## 1. 원칙 (화면을 이것에 대어 봄)

1. **첫 화면에 학습.** 강의를 열면 휴대폰(390×844) 첫 화면 안에 첫 학습 항목이 보인다. 틀(머리줄 · 제목 줄 · 단계 탭)은 합쳐 200px 이내.
2. **한 번에 하나.** 한 화면의 주된 행동은 하나(채운 검정 단추 하나). 같은 일을 하는 것을 두 벌 두지 않는다 — 플레이어 하나, '다음' 하나, 속도 고르기 하나.
3. **조용한 화면.** 무채색 바탕 + 강조색 하나(금색 `primary`) + 맞음 · 틀림 색 두 가지. 장식용 이모지 · 그라데이션 · 깜빡임 · 늘 움직이는 효과 없음. 상자 안에 상자를 넣지 않는다(여백과 선으로 나눔).
4. **손가락 크기.** 누르는 것은 모두 44×44px 이상(작게 보여야 하면 보이지 않는 누름 영역을 넓힘). 입력 칸 글자는 16px 이상 — 아이폰이 화면을 확대하지 않게.
5. **마우스를 올려도 내용이 안 바뀐다.** hover 는 모양(밑줄 · 배경)만. 폰 화면에 '마우스' · '클릭' 이라고 쓰지 않는다('누르세요').
6. **끝에서 다음으로.** 마지막 단계 끝에 '학습 완료 · 다음 강의'. 강의를 마치려고 위로 올라가게 하지 않는다.
7. **말은 쉽게, 하는 일대로.** 영어 대문자 장식 라벨('ACOUSTIC COGNITIVE SYSTEM', 'CORE TRACK')과 과장 문구('AI', '두뇌 반사신경', '0.5초 만에')를 쓰지 않는다. 기능 이름은 실제 동작대로. 음성의 출처는 쓰지 않는다(AGENTS.md).
8. **정답은 시도한 뒤에.** 학습자가 답하기 전에 정답 글 · 정답 소리에 닿는 단추를 두지 않는다(과정 화면 공통).

## 2. 글꼴

- 한 가지 글꼴: `--font-sans`(Pretendard → 시스템 한글 글꼴). Pretendard 자체 호스팅은 운영에서 첫 화면 속도(LCP)를 다시 재어 나빠지지 않을 때만.
- **한글에 고정폭(`font-mono`) · 자간(`tracking-*`) · `uppercase` 금지.** 숫자를 나란히 맞출 때는 `tabular-nums`.
- 고정폭은 시계(00:42) · 코드처럼 글자 폭이 같아야 하는 곳에만.

## 3. 글자 크기 — 6단계

| 이름 | 크기 | 쓰는 곳 |
|---|---|---|
| caption | 12px | 숫자 · 보조 글. **이보다 작은 글씨 금지** |
| label | 14px | 단추 · 라벨 · 탭(휴대폰에서 누르는 글은 14px 이상) |
| body | 16px | 본문 · 학습 문장 · 입력 칸 |
| title-s | 18px | 카드 제목 |
| title | 22px | 강의 제목(휴대폰 20px) |
| title-l | 28px | 과정 제목 |

학습 글자 크기 조절은 틀에 하나만(모든 과정에 같게).

## 4. 색

- 무채색 토큰: `ink` · `ink-soft` · `ink-faint` · `surface` · `raised` · `sunken` · `line` · `line-strong`.
- 강조색 하나: `primary`(금색) — 지금 단계 표시 · 주된 단추에만.
- 맞음 `success` · 틀림 `danger` 두 가지만 더함. `amber-` · `blue-` · `emerald-` · `green-` · `rose-` · `red-` · `teal-` 같은 직접 색 금지.
- 다크 모드: 모든 글자 대비 4.5:1 이상(큰 글자 3:1). 밝은 테마 전용 색을 쓰지 않는다.

## 5. 모양

- 모서리 2종: 12px(단추 · 칩 · 입력 칸) · 16px(카드). 동그란 아이콘 단추만 완전히 둥글게.
- 그림자는 떠 있는 층(서랍 · 대화상자 · 고정 막대)에만. 페이지 안 카드는 1px 선.
- 아이콘은 한 벌의 선 아이콘(SVG, 글자색을 따름). 이모지를 아이콘으로 쓰지 않는다. 학습 내용 속 이모지는 뜻이 있을 때만.
- 움직임: 처음 나타날 때 한 번만. `animate-pulse` · `animate-bounce` 금지.

## 6. 강의 화면 틀 — 모든 과정이 같은 순서

1. **머리줄** 56px — 휴대폰: 로고 · 검색 · 메뉴(이용권 상태는 메뉴 안). 데스크탑: 과정 이름 줄 추가.
2. **제목 줄** — '← 과정 목록' · 강의 제목(휴대폰 20px · 데스크탑 26px) · 북마크 아이콘.
3. **단계 탭**(공통 부품) — 휴대폰: 한 줄(번호 · 지금 단계 이름). 데스크탑: 한 줄 탭. 모든 과정이 같은 모양.
4. **학습 내용**(과정 화면). 과정 소개 카드(광고 문구) 없음.
5. **끝 막대**(공통 부품) — '학습 완료 · 다음 강의' 와 이전/다음 강의.

전체 듣기는 그 과정의 학습 순서에 맞는 자리 한 곳에만(시도 전에 정답을 들려주지 않게).
